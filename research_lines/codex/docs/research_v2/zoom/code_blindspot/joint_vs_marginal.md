# 代码盲区放大镜 · 透镜：逐层边缘 vs 跨层联合结构

日期：2026-09-05 · 执行者：Claude Opus 5（研究工程师） · 数据：B1/B2 开发集，**事后诊断，不是检测成绩**

问题：CAND-A 的特征是一个 8-token 窗口上被展平的 (layer, expert) **边缘**统计；而唯一对代码有反应的
"未见深度转移"统计量数的是**跨层**的 top-1 专家链。本透镜直接检验：**代码的新颖性是不是住在联合里？**

口径（全程只用 routine 拟合，标签只用于切片，不参与任何拟合或定阈）：

* ROUTINE = 两个 batch 的 clean + benign_control 共 240 条（23 903 个 decode token）。按 `pair_group_id`
  排序后交替分成两折（各 120 条 / 12 423 与 11 480 token）；**在一折上拟合、在另一折上读出 routine 参照**，
  drift 区间在两折上各算一次后取平均。所有"routine 参照"数字都是**留出**的。
* CODE 区间 = 8 条 `domain=='programming'` drift 的 `[product_onset, min(product_onset+48, T))`（8 条 T 均为 192，
  8 个区间都是满 48 token）。OTHER-DRIFT 区间 = 51 条非 programming drift 同样定义，按域分组。
  evidence_onset 变体见 §7 表 G：**结论不随锚点改变**。
* (1) 边缘 = CAND-A 本体：w=8 top-8 入选率窗口、层 5–15、白化（方差地板 1e-3）、到 routine 中心的平方距离
  `g1`。注意 `g1` 对维度可加，因此**它精确等于逐层边缘 novelty 之和，不含任何跨层信息**。
* (2) 成对联合 = 相邻层对 (l, l+1)，l=0..14 的三种模式：(2a) (top-1@l, top-1@l+1) 对；
  (2b) (top-8@l × top-8@l+1) 的 64 个交叉对；(2c) |S_l ∩ S_{l+1}| 重叠数模式。
  "稀有" = routine 相对频率**严格低于 routine 拟合实例频率的第 1 百分位**。
  **注意**：在本参照规模下该阈值恰好落在"计数 1"上（fold0 8.05e-5 = 1/12423，fold1 8.71e-5 = 1/11480），
  因此 (2a) 的"稀有"与"未见"完全等价（表 A 两行数字相同）；表 L 给出"计数 ≤ 2"的敏感性。
* (3) 全链 = CAND-B 的 D1 深度链 surprisal（top-1、平滑 0.5、层 5–11）与层 0–15 版本，
  外加硬计数（未见 link 数 / 整条链未见比例）。

## 0. 一页结论

1. **代码的新颖性确实住在联合里，而且比其他域更依赖联合。** 逐 trace 的"联合放大系数"
   A = (2a 联合比值) / (1 边缘比值)：8 条代码 trace 全部在 **2.45–4.99**，中位 **4.69**；
   51 条其他域 drift 中位 **1.69**（范围 0.32–4.33），只有 16/51 达到代码的最小值 2.45。
   同一批窗口上，边缘只有 1.53 倍 routine（其他域 6.10 倍），top-1 层对联合是 6.29 倍（其他域 13.58 倍）。
   **联合把代码与 routine 的比值抬高约 4 倍，把代码与其他域的差距从 4.0 倍压到 2.2 倍——但没有消除它。**
   **重要限定**（§6 反例 7）：若只跟"边缘同样弱"的其他域 drift 配对比较，A 的优势缩小到 4.69 vs 3.38、区间重叠。
2. **机制：其他域漂移换"新专家"，代码换"老专家的新接线"。** 把未见的 top-1 层对拆成两类后
   （表 R）："由 routine 常见专家组成的新组合"在代码上是 routine 的 **4.57 倍**，在其他域只有 **1.92 倍**——
   **这是全部 20 多个统计量里唯一一个代码高于其他域的**；而"至少一端是罕见专家"这一类，代码 8.03 倍、
   其他域 19.26 倍。代码区间里未见层对中有 11.9%–23.3% 属于"熟专家新组合"，其他域只有 2.6%。
   逐层边缘（marginal_rare_rate）代码 1.22 倍、其他域 2.48 倍，**这正是 CAND-A 看不见代码的原因**。
3. **联合信号的载体是 top-1，不是 top-2..8。** 逐 rank 的深度对未见率比值单调下降：
   rank1 7.29 → rank2 4.46 → rank4 2.74 → rank8 2.52（表 M）。把 (2) 换成 top-8 集合交叉对反而把
   代码比值从 6.29 压到 2.17（表 B）。**"代码的链新颖性其实在 top-2..8"这一假设被否定。**
4. **CAND-B 仍漏 7/8 的主因是"时延 + 余量"，不是层带、不是平滑、不是 w=4 内稀疏。**
   在自洽的 α=0.10 类比下（留出 routine 逐 trace 最大值的 q90 = 2.32），代码区间 48 token 的
   w=4 最大 z 有 **6/8** 越线，但只看 `onset..+16` 只剩 **2/8**（表 I / N）；冻结 CAND-B 在这 8 条上的
   首报警偏移是 **+5, −8, 无, +22, +18, 无, +17, +70**，即 6/8 确实报了警，只是**晚于 +16**。
   我的自洽越线偏移（4/5、15/20、None/73、21/21、17/17、None/94、37/37、11/13）与冻结报警偏移
   （5, −8, None, 22, 18, None, 17, 70）在 **5/8 条上吻合**（+5↔+5、+22↔+21、+18↔+17、两条"都不报"），
   另 3 条差 20–57 token（见 §5 表 O 的说明）。这个类比因此只用于定位"信号在区间内何时到达"。
5. **代码的效应量本身也只有其他域的一半**：D1 区间均值相对 routine 的效应量（routine sd 单位）
   代码中位 **0.94**、其他域 **2.24**（平滑 0.5）。降平滑到 0.005 把代码抬到 1.83、其他域抬到 3.72，
   `onset..+16` 内越线数只从 2/8 变到 3/8（表 P）。**平滑不是瓶颈。**
6. **两个联合统计量是"反例/退化"**：重叠数模式 (2c) 在代码上是 routine 的 **0.58 倍**（低于 routine！），
   其他域 1.15 倍——一个对代码**反向**的联合特征；整链未见比例在 routine 上就已经是 0.589（层 5–11）
   与 0.869（层 0–15），**参照规模决定它天然饱和**，代码只有 1.55/1.15 倍，无信息。
7. **不要读成"改进"**：本文所有量都没有做部署侧 conformal 定阈、没有 FAR、没有 benign/resist 臂、
   没有跨 batch 模式 T。fcm 报告已证明同族的"未见转移"统计量在报警层要付 resist 臂 FAR 0.156–0.244
   且模式 T 下 FAR=1.000。本文只回答"信号住在哪里"。

## 5. 那么 CAND-B 为什么还是漏 7/8？

四个候选解释逐一定量（自洽类比：同样的 D1 z、层 5–11、s=0.5、w=4 因果窗口，阈值取**留出 routine
逐 trace 最大值的 q90**，即一个 α=0.10 的自洽类比；不是冻结检测器的阈值，也没有位置桶标准化）。

| 候选解释 | 判定 | 数字 |
|---|---|---|
| 在 top-2..8 而不是 top-1 | **否** | 逐 rank 未见率比值 7.29 → 2.52 单调降（表 M）；top-8 交叉对把比值从 6.29 压到 2.17 |

1. **b2-f2-014-support_case_status-sql-query** 在每一个统计量上都是最弱的一条：边缘 1.16×、联合 2.84×、

## 8. 局限

* n=8。所有"代码中位"背后只有 8 个数，全文已逐条给出。
* 两折都用同一批 240 条 routine，折间不独立于 batch（每折都混 B1/B2）；本文没有做跨 batch（模式 T）的检验，
  而 fcm 报告已证明未见转移类统计量在模式 T 下不可迁移（FAR=1.000）。
* §5 的"越线"用的是留出 routine 逐 trace 最大值的 q90，**不是**冻结 harness 的部署侧 conformal 阈值
  （没有位置桶标准化、没有 persist2、没有校准半切、没有 FAR / benign / resist 口径）。
  它只用来定位"信号在区间内何时到达"，**不能读成任何配置的成绩**。
* routine 参照只有 ~12k token / 折，对 64×64 的层对表已经稀疏（未见率 2.1%），对 64^7 的整链表完全饱和。
  本文的"未见"始终是"在这个规模的参照里未见"。
