## 1. TCD（三通道分解）

**与 §B 的一致性。** 通道 S 与通道 J 依据扎实：S 直接对应 B1.1 的 unseen8/surprisal8；J 是 `code_blindspot §1.5`
那个 79%/21% 分解的**正确算子化**（2.38× 里 79% 来自边缘机会，所以必须减 log P(a)P(b)），而且 TCD 诚实地写出
"边缘校正后代码的条件率只排第 3"——不隐瞒代价。S/R 严格互补的坐标划分在构造上成立，J 与 S 的正交论证也成立。

**核心问题（V1）。** 整篇的动机是"在单一标量里，支持集内重排被稀释到噪声以下，**永远不可能自己越过**由全路径
校准的阈值"。这句话预设了被稀释的那一份**有**信号。简报所引的源文件说的恰恰相反：在最低方差十分位**之外**，
8 个域彼此不可分；唯一见过的集合内重排信号是概率版 rmass，跨 batch 崩塌。所以把 CAND-A 砍掉 78% 的能量得到 R，
不是"给 R 一个自己的零分布让它有机会越线"，而是"把已验证候选降级成一个未验证的弱通道"。TCD 自己的预测表也
承认这点（代码 route-only 0–1/8；R 的效应量"只有其他域一半且迟"）——即 R 做不到它被发明出来要做的事。

**由此派生的预注册缺陷。** 格 D 是全篇的增量判据："F1 融合 vs **单通道 R（= 已冻结 CAND-A 家族）**"。R **不是**
CAND-A：CAND-A 含稀有坐标，R 不含。正确的对照必须是**完整的冻结 CAND-A**，否则测的是"三通道 vs 被砍过的
CAND-A"，几乎必然通过而毫无意义。这一格必须改。

**融合与 FAR。** 最强的一段。e 值算术平均在任意依赖下有效（比 DRS 的乘积更对），阶段 2 在 CAL_B 上对融合
统计量重做全路径保形，使每 episode 预算与通道相关性无关地精确成立——这是四篇里最干净的 FAR 论证，也正面
回答 F1/F5。副作用：一旦有阶段 2，阶段 1 的"分通道 FAR 预算"就不再约束任何东西，只是展示用；文中把它列为
机制卖点略有夸大。另需注意：算术平均意味着**一个强通道被除以 3（−1.1 nat）**，若 R、J 确如上分析般弱，
融合在同预算下**严格劣于**单独跑 S 或 A。格 G（通道相关矩阵）是必要的，但它测不出这一点——需要再加一格
"融合 vs 完整 CAND-A"。

**及时性。** 自己写明："分解不改变裕度"，而 B2.4 说裕度主导延迟。预测 R+8 0.30–0.38，增益只来自 J 的 w=4
（2–3 token）。诚实，但这意味着 TCD 对简报 A 的"不可逆点前检出"几乎没有贡献。

**其他。** 未处理 C1（192-token、98/160 组 ≥64 token）与 B3（384-token）的路径极大分布错配——DRS 与 TSSM
都处理了。删失 carry-forward 的保守性作者自己指出了（风险 4）。

**评分**：一致性 3 / 避开死路 4 / 及时性 2 / FAR 可控 5 / 融合就绪 5 / 可预注册与功效 4 / 成本 4 = **27**

## 2. DRS（双参照序列检验）

**与 §B 的一致性。** 诊断段是四篇里与源文件贴合最紧的：`normal_manifold_early_evidence_audit_report.md §3.1`
原话是"在 +8 可比较 matched windows 中，normal controls 几乎从不越过 C1 threshold，而多数 drift maximum 仍然
只是'高于 control、低于全路径 threshold'……瓶颈是 normal full-path peaks 与 early drift magnitude 的绝对重叠，
不是单纯降低 threshold 就能无代价解决"。DRS 的"换多重性装置而不是降阈值"正是对这句话的直接响应，是本轮
四篇里唯一**攻击 B2.4 指认的主导项（阈值裕度）** 的设计。

**三处必须修正的地方。**
1. **V3（载荷性误引）**：L_eff 的推导用错了数。O22 给的相邻 token 分数相关是 0.324/0.459，而 DRS 的 look 是
   50% 重叠的 w=8 窗口，相关性远高于此。修正后阈值大约坐在 99 百分位而不是 99.5–99.75，"从 95 到 99.5 要多花
   3–5 token"的算术随之缩水。**必须重算，而且这个数在现有 routine 缓存上是可直接测量的**——把它留成推导而
   不去测，正是本镜头要扣分的"简报给了数字却改用定性说辞"。
2. **V5（定理过强）**：γ 指数破坏逐路径支配；跨通道乘积在依赖下不是 e 值。操作上无害（S4 的保形路径极大兜底），
   但§9 的新点 #5"收缩支配 ⇒ Ville 界仍成立"必须撤回或改写为"经验支配 + 保形兜底"。另外 γ 在 `N_fit` 上被拟合
   成使 Ville 界匹配，那么在 `N_cal` 上测得的 ρ 主要度量 fit→cal 的迁移，而不是"相依性罚项"——ρ 的语义要改写。
3. **O12 的正面反证没有被量化**：`algorithm_design_logic_foundations.md` O12——"21 条误报中 **17 条连续越线至少
   2 次**；CUSUM 被合法语义 mention 与重复 `\n` 长期积分"。这直接说明 routine 里"两次中等 look"这种货币**也很
   便宜**。DRS 的收益全部来自"两次 95 百分位 ≈ 一次 99.5 百分位"，而 O12 说正常流量本来就常出两次。半衰期 32
   look 的收缩是正确的缓解，但收益幅度必须用这个已有的 17/21 去校准，不能留作预测。

**避开死路。** 处理得很细：E14 的三点差别（向量位移 vs 标量、带 gap 的非重叠长历史 vs 紧邻重叠窗口、**尺度用
routine 固定单位而不是 trace 自身尺度**）是有实质的；且 §6.3 判据 3 把"P2 ≤ 0 ⇒ 立场 B 被证伪"写死。它没有把
"用累积降 FAR"偷渡进来——明确写了成功判据里没有任何一条是 FAR 更低，且要求与 CAND-A 在同一 α 下比。合格。

**FAR 可控。** 最终由 routine 路径极大保形兜底，且 ρ>3 有预置失败线。分段 FAR 完整。扣分点仅在于对外宣称的
anytime 保证并未成立（见 V5），以及两半符号差风险与其他三篇同等。

**预注册。** 四篇里最锋利：P2 是唯一一个**能一次性证伪本提案核心主张**的配对检验（DRS vs 只用 A 通道），
P3 被明写为"设计上就是预期失败的诚实记录格"，且唯一声明了继承性 winner's curse。这是可预注册性的标杆。

**评分**：一致性 3 / 避开死路 4 / 及时性 5 / FAR 可控 4 / 融合就绪 4 / 可预注册与功效 5 / 成本 4 = **29**

## 3. TSSM（两阶段切换–持续状态机）

**最好的一个想法。** 第一阶段是本轮四篇里最漂亮的机制推理，而且**算术上站得住**：O4 说"正常 trace 的最大局部
JSD 与 drift onset 同量级，onset-vs-normal-max AUROC 0.502/0.472"。把它读成"onset 的幅度 ≈ 一条正常 trace 约
380 个位置里的最大值"，即 onset 大约在**位置级分布的 99.7 百分位**——于是"不能阈值化"（因为要压住每条正常
trace 的那一个峰）与"能以固定速率 ρ=0.02 提出候选"（因为 98 百分位就够碰到它）**同时为真**。这把一条否证
变成设计输入，是真正的新读法，也忠实实现了 `agent_v2_layer_zoom_report.md §7` 的四条建议（含第 3 条"允许第二个
切换候选"与第 4 条"不再把 novelty 下降等同抵御"）。S8 的返回三重正向证据、"检出永不回收"、显式删失状态、
以及"首次越线是否先于真实 onset"的一级审计格，都是对 DRR/LDC 失败的正确回应。

**致命处在第二阶段（V6）。** `e_s = (1/p̂)^{1/w2}`，w2=8。在 H0 下 p̂ 超均匀，`E[log e_s] = 1/8`，于是
`logE_k` 以 **0.125 nat/token 线性增长，与是否漂移无关**。后果按 TSSM 自己的校准规则推：
- 一条 384-token 的 routine trace，若首个候选在 t≈50 开启，episode 到 EOS 累计约 **0.125 × 334 ≈ 42 nat**；
- `h_conf` 定义为 routine 上每条 trace 的 `max_k(logE_k − log(1/λ_k))` 的次序统计量 ⇒ `h_conf` 落在 **40+ nat**；
- 漂移侧即使每 token 拿到 p̂≈1e-3（`log(1/p̂)/8 ≈ 0.86`），也需要 **≈50 token** 才能到线；p̂≈1e-4 也要 ≈44 token。
⇒ **确认延迟结构性 ≥40–80 token**，与本文自己预测的 provisional R+8 = 0.35–0.45 直接矛盾。λ_k=2^-k 带来的
log 64 ≈ 4.16 nat 相比 42 nat 的零漂移是二阶项。

**同一缺陷还把架构的主卖点反转。** `M_max` 满时"evict argmin logE"——由于 logE 随 episode 年龄单调增长，
被逐出的**总是最新的候选**，而幸存的总是开得最早的。"错的早候选自然不积累证据而过期"在这个统计量下是
**反的**：错的早候选恰恰积累得最多。这一条与"并行候选解决 oracle-onset 问题"的整个论证冲突。

**这是不是 §C 的伪装重试。** 是半个。C 列禁的是"用持久性/块/CUSUM **降 FAR**"，TSSM 明确不作此主张，形式上
合规；但 O12 的实质不只是 FAR，而是"无条件累计会被合法 mention 与重复换行长期积分"——TSSM 的 episode 内
无界累计正是这个形式，且没有任何收缩/漂移补偿（DRS 恰恰因为 A5/O12 才引入 shrink）。

**另一处与 §B 的张力。** S3/S4 用 `S_e` = 候选前 24 个 token 估出的稳健尺度，去归一化 **384 维**向量——24 个
样本估 384 维尺度，且是 trace 自身尺度。这正是 E14（`AUROC 0.98→0.81`、边界<23 子集 0.46）的失败形态，
也正是 DRS 特意避开的那一点（"尺度用 routine 固定单位，不用 trace 自身尺度"）。TSSM 没有讨论 E14。

**FAR 与输出。** FAR 原则上可控（零分布是在 routine 上跑同一台状态机收集的），但工作点被最长的 routine
episode 决定，与 B2 已知的长度暴露（长度三分位 FAR 0.000/0.061/0.206）叠加。契约 E 要求"逐 token 校准分数
（在正常流量上分布已知）"，而 `s_t = max(calibrated(z1), max_k calibrated(logE_k))` 不是保形 p 值流，其正常
分布未被给出。分段 FAR 报告则是四篇里最完整的（额外单列 prior_baseline 通道、静默抵御臂、各类删失状态）。

**评分**：一致性 2 / 避开死路 3 / 及时性 2 / FAR 可控 3 / 融合就绪 3 / 可预注册与功效 5 / 成本 3 = **21**

## 4. MD3（最小可部署三通道监视器）

**与 §B 的一致性：本轮最高。** 几乎每个组件都是已被独立验证的冻结量，引用逐条可核（OR 三个数字与
`lead_sample_level_findings.md` 改进 #2 逐字一致；unseen8 29/40 vs 6/160、surprisal8 37/40、文本规则 301 条零误报
7/8 中位 +17、JSON 47.5%、桶规则、层选择 48/55·54/55 全部对得上）。C 列对照表是四篇里最干净的：persist2 只因
属于冻结候选定义而保留并明确否认降 FAR 的说法；连续性剖面是描述性字段并预置删除规则；bucket-free 判决单格
以近零成本了结一个真实的两线冲突。它也是唯一给出**流形自身漂移监控与再校准节奏**的提案——这条两条线都没做过。

**两个必须修的缺陷。**
1. **V7（"部署侧"的误用 + 内部矛盾）**：C1 相对 B3 是源侧，而不是 B2.7 说的部署侧；C1 还偏短（160 组中仅
   98 组 ≥64 token），用它定"完整路径最大值"阈值再拿到 384-token 的 B3 上，路径极大分布必然不匹配
   （B5.16 的直接教训）。而 §4.2 与 §5.2 P1 对阈值来源的表述互相矛盾。修法很清楚：**主格用目标 batch 的
   routine 半份交叉（模式 D）**，把"C1 预置阈值能否出厂"从次族提到一级——那才是 MD3 真正独有、也真正有
   产品价值的那一格。
2. **V8（互补性被高估）**：S 与 A 主要量同一机制（78% 的白化能量就在 S 的坐标上）。Bonferroni 三分预算因此
   是在两个高度相关的通道上付了两份代价。至少要把 routine 上的 (S, A, B) 相关矩阵列为一级诊断（TCD 的格 G
   值得照搬），并预置"若 |ρ(S,A)|>0.7 则把预算重新分配为 S+A 合并一份"的规则。

**及时性。** 明说不买：延迟 8→5 全部来自 OR，而这个数在源文件里被标注为事后选择（V9），且未在模式 T /
S2/S3 / bootstrap 下验证过。对阈值裕度（B2.4 的主导项）零贡献。这是 MD3 自觉的取舍，但也意味着它对简报 A
的"不可逆点前检出"目标只是维持现状。

**融合就绪与可运维性：四篇最高。** 逐 token 逐通道保形 p 值流 + EVENT（证据窗、归因坐标、支持集标志、概率
载荷）+ PROFILE + SESSION（剩余预算），文本臂被正式声明为契约外第二模块且要求所有主指标在 T 关闭时可算。
契约 E 要求的输出形态，只有 MD3 完整给出了可被上层融合层直接消费的版本。

**评分**：一致性 4 / 避开死路 5 / 及时性 2 / FAR 可控 5 / 融合就绪 5 / 可预注册与功效 4 / 成本 5 = **30**

## 6. 综合建议：如果只能造一个检测器

**骨架取 MD3。** 冻结通道 S（surprisal8 连续 + unseen8 归因标志）与**完整的** CAND-A（含稀有坐标，不做 TCD 的
砍半）、代码域零误报文本规则 T 作为契约外第二阶段确认器；采用 MD3 的输出契约（逐 token 逐通道保形 p 值流 +
证据窗 + 归因坐标 + 支持集标志 + provisional/confirmed_routing/confirmed_text + 剩余预算）、分段 FAR 口径、
定阈者透明化、流形漂移监控与再校准节奏、以及 bucket-free 判决单格。**但把主格阈值改为目标 batch 的 routine
半份交叉（模式 D）**，C1 只用于"预置阈值能否出厂"这一格，并把该格提到一级。

**多重性装置取 DRS。** 用"每次 look 的保形 p → e 值 → 带收缩的有限记忆 e-process"取代 MD3 的"每通道路径极大 +
Bonferroni"，因为后者对 B2.4 的阈值裕度零贡献，而前者是四篇里唯一可能动它的机制。保留 DRS 的两个工程件：
`shrink` 的显式半衰期（回应 A5/O12 对无界累计的否证）与 **ρ = h_conf/log(1/α) 作为带预置失败线的一级报告量**。
同时保留 DRS 的第二参照，但只以**独立保形通道**的形式（routine 度量、routine 尺度、带 gap 的非重叠历史块），
不作为分数内的减法。

**融合与预算取 TCD。** 通道→e 值后用**算术平均**（任意依赖下有效，优于 DRS 的乘积），再把融合统计量在**另一个
校准半**上做一次全路径保形——这一步让每 episode 预算与通道相关性无关地精确成立，同时兜住 e-process 理论上的
所有漏洞。另加 TCD 的通道 J（相邻层 top-1 对的**边缘校正**耦合新颖度），它是唯一与 S 在构造上正交、且忠实
实现 79%/21% 分解的量，成本 0.7 µs/token。保留 TCD 的 `R_p` routine-only 跨半稳定性门作为对 F4 的正式回答。

**提出器取 TSSM。** 加入晚层 L11–15 的**时间自对比**统计量，**只按固定速率 ρ=0.02 校准、不承担任何 FAR 预算**，
仅用于（a）开启/锚定证据窗，（b）为相对通道提供候选前基线，（c）作为归因输出的一个字段——绝不单独抬升状态。
并保留 TSSM 的三条纪律：并行候选（上限 2–3，但**逐出规则改为按年龄或按 e 值增量，不按累计 logE**）、返回原任务
必须由正向证据判定且**检出永不回收**、EOS 时输出显式删失状态且永不判为抵御。同时照搬 TSSM 的"首次越线是否
先于真实 onset"一级审计格与 MD3/TCD 的通道相关矩阵诊断格。

**明确丢弃：**
- TCD 的通道 R（频繁坐标白化能量）——`code_blindspot §1.1` 说那个坐标集合上 8 个域彼此不可分；用完整 CAND-A 代替。
  同时废掉格 D 的对照（必须对完整 CAND-A，不能对 R）。
- TSSM 的 `e_s=(1/p̂)^{1/8}` 累加器（零漂移 0.125 nat/token）、`S_e` 自身尺度（E14 形态）、argmin-logE 逐出规则。
- DRS 对 anytime-valid 的**宣称**（保留保形兜底，ρ 降为描述性诊断）；乘积式跨通道合成（换成 e 值算术平均）。
- MD3 把 C1 称作部署侧的说法与 §4.2/§5.2 的阈值来源矛盾；以及"S/A/B 互补"这一未经检验的措辞。
- 位置桶封顶 3 的默认：lead #13 支持 4/5 桶（延迟 8→5），而 C1/B3 的池子（≥90–160 条/半）已经付得起 ≥60 条/半
  的成本。改为"按数据支持能开几桶就开几桶，上限 5，桶数 ≤2 时告警"，并保留 bucket-free 消融格。

**四篇一致、必须整体继承的部分（不要在合并时丢掉）：** 不用持久性/块/CUSUM 降 FAR；不做层选择、不做层维特征；
无 warm-up；不做形态条件化与去结构化 routine 池（JSON 作为 B3 显式设计变量，池子不清洗）；代码域 = 路由
provisional + 零误报文本规则 confirm，route-only 与 route+text 单列；抵御/执行子分类只作非门控描述性输出并
并报 oracle 锚点版；product_onset 主锚点 + 双锚点记录；384-token horizon 与 stop reason 作删失；预注册单格 +
Holm；以 scenario/group 为重抽样单位。另外补一条四篇里只有 DRS 写了的：**层带与窗宽是从 36 个候选事后挑出的
继承性适应选择，本轮唯一干净的证据是配对差值，不是绝对数**——这句话应该写进合并后的预注册。
