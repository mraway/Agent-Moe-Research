## 1. TCD：三通道分解

### 1.1 零假设与校准有效性

零假设是隐式的："routine 路径与校准路径可交换"。分两阶段实现，而**两阶段的写法在文内互相矛盾**，
这是本提案最重要的统计问题：

- **§2 伪代码**：`p[c] = (1 + #{g ∈ CAL_A : Mcal[c][g](k) ≥ M[c]}) / (n_A+1)`——参照集是**风险时钟 k 处的
  逐 look running max**，然后在任意 t 上以 `p_fused ≤ 0.10` 报警。
- **§5 步骤 3**：在 `N_cal_B` 上取 `E_fused` 的**整路径 running max** 的第 `⌈(n_B+1)(1−α)⌉` 阶次序统计量作为
  **固定阈值**。

后者是有效的（路径极大的次序统计量，等价于 MD3 的 C7，`P(∃t: M_t ≥ h) ≤ α` 精确成立）。
前者**不是**：对每个固定 k 有 `P(p(k) ≤ α) ≤ α`，但 running max 在 k 上的**秩不是单调的**（一条路径可以早期极端、
后期被别的路径超过），所以 `P(∃k: p(k) ≤ α)` 不受 α 控制。提案 §1 与 §5 反复声称的
"**每会话 α = 0.10 由第二阶段的可交换性精确保证，与三通道相关性无关**"，只对固定阈值那一版成立。
两种写法必须二选一，且只能选后者。

**删失处理的符号被写反了。** §10 风险 4 写"删失处理（校准路径比 k 短时 carry-forward）是保守的"。
实际方向相反：短校准路径在大 k 处 carry-forward 的是它们**较小的**最终 max，参照分布随 k 下移，而被评价路径的
running max 单调上升，于是 `#{Mcal ≥ M}` 变小、`p_fused` 变小——**对长 trace 是反保守的**。这恰好作用在
已知 FAR 最高的那一段（长度三分位 FAR 0.000/0.061/0.206）。这条自评错误会让作者低估主表风险。

其余校准设计是四份里最完整的之一：位置桶（end//32、尾桶合并至 ≥30 条、上限 3 桶）、`N_fit`/`N_cal_A`/`N_cal_B`
group 不重叠、定阈 trace 身份与"剔除 top-1/3/5 后的 FAR"、JSON 含/不含分层、两半带符号差 ≤0.10 **进了主格 C**
（正确）。`R_p` 的 routine-only 跨半稳定性门（q90 相对差 ≤10%，两个 fold family 都要）是回答 F4 的干净做法：
预注册、不看正例、失败即写"F4 = 否"。这是本轮最值得复制的一个小设计。

**融合的数学是对的**：`e = κp^{κ−1}`（κ=0.5）是 admissible calibrator；e 值的**算术平均在任意依赖下仍是 e 值**
（线性期望，不需要独立性）。作者明确指出乘积/Fisher 需要独立性会反保守——这一判断正确，且与 DRS 形成直接对照。
但要注意：既然最终还要在 CAL_B 上对 `E_fused` 重新做保形，e 值机制事实上只充当**一个合并函数**，
所有有效性来自那一次保形。这不是错误，但"任意依赖下成立"的卖点被后一步吸收了大半。

### 1.2 预注册与多重性

7 个格：A–D 为确认性 family（Holm，family α=0.05），E 为独立 scoped family，F/G 描述性（BH，明标"非确认"）。
明写"每个假设一格，不取跨格最大值——B3.9 的教训"。区间以 scenario/group 为重抽样单位。这是四份里格数最多但
分层最清楚的一份。

**功效**（B3 规模：主事件正例 120、routine 200、代码 20/方向）：
A（R+16 ≥0.55，真值 0.65）约 60%；C（FAR）>95%；D（McNemar 融合 vs 单通道 R，净 +12/−3）约 70%；
E（代码 R+48）>90%；F（子分类 AUROC）约 60%。作者自己写下"A 与 F 只有 ~60% 功效，A 的失败必须解读为
'未证实'不是'证伪'；只有 C、D、E 有确认性力度"——这是正确的、也是直接吸收了 §2.6 教训的表述。

**但主次序放反了**：本提案的全部主张是"分解值钱"，那就是格 D；D 被放在 family 第四位，而功效最低的 A 被当作
主格。应把 D 提为主格、A 降为伴随的绝对水平描述，否则一个 60% 功效的绝对门槛会主导 go/no-go。

### 1.3 陷阱检查

| 陷阱 | 判定 |
|---|---|
| 跑遍格子 | **躲开**。单格 + Holm + 明文禁止跨格取最大 |
| ±5 容差 | **躲开**。product_onset 主锚、announcement/topic_entry 并列，"容差带按两者之差定" |
| 未配对延迟 | **部分躲开**。格 D 是配对 McNemar（但只对 R+16）；"禁止只报命中样本的中位延迟"写进了 §6；然而格 B 的端点仍是"命中中位延迟"，且**没有任何格要求在共同命中集合上配对比较延迟**。TCD 若想主张及时性，缺一个配对延迟格 |

另：代码格 E 的 `α_prov = 0.25` 意味着**每四条正常 episode 就有一条 provisional**；"provisional 领先文本确认的
中位 token 数"只在同时被两者命中的样本上定义，是又一个条件于命中的量。E 格必须同时报告 provisional 自身的
LR+（recall/0.25），否则"领先 8 token"这个门槛没有信息量。

### 1.4 结论

统计骨架好，机制论证与简报最贴合，`R_p` 门与通道分预算是真贡献；但**核心有效性声明依赖一段被写成两种互不相容
形式的 p 值构造，且删失方向的自评符号写反**。两者都可修（删掉逐 look 版本、把 carry-forward 改成
"只用 ≥k 的校准路径并声明分母"或直接用固定路径极大阈值），修完之后它的 FAR 可控性会从 3 升到 4–5。

## 2. DRS：双参照序列检验

### 2.1 零假设：四份里写得最清楚，也是唯一被形式化的

§4.1 明确写出会话级 H0（逐 look 保形 p 值的**条件**超均匀），并且诚实地把它拆成两层：
split-conformal 只能给**边际**超均匀；条件超均匀是近似的、必须被测量。然后给出三重处置（抽稀 s=4、
相依性折扣 γ 由 routine 拟合、最终以保形路径极大为准），并把
**ρ = h_conf / log(1/α_sess)** 定为一级报告量、`ρ > 3` 定为预注册失败判据。

这是本轮最有价值的一个统计发明：它把简报 M3 那句"重叠窗口不是独立样本"从告诫变成**一个可测量、可预注册失败的
数**。四份提案里只有这一份直接测量了自己的理论假设。

### 2.2 但 e-process 的推导有两处硬伤

**(a) 两个 e 值相乘不是 e 值。** `E_t = shrink(E_{t−1})·(e^A_t e^R_t)^γ`。`e^A` 与 `e^R` 由**同一时刻、重叠窗口**
的两个保形 p 值算出，彼此强相关（§8 风险 4 自己承认"都建立在同一白化坐标上"）。在任意依赖下
`E[e^A·e^R] ≤ 1` **不成立**——这正是 TCD 选算术平均而不是乘积的理由。DRS 把这件事写成了**功效**问题
（"若相关 >0.7，收益被压掉"），但它其实是**有效性**问题。

**(b) `shrink(x) ≤ x ⇒ E_t ≤ M_t 逐路径成立`的论证漏掉了 γ 指数。** 对 `x < 1`（证据不利的 look），
`x^γ > x`（γ∈(0,1)），所以逐因子支配不成立，`E_t ≤ M_t` 为假。
（顺带：`e^γ` 本身**确实**仍是 e 值——由 Jensen，`E[e^γ] ≤ (E[e])^γ ≤ 1`——所以 γ 折扣这一步可以救回来，
救不回来的是 (a) 的乘积步。）

后果：Ville 界、`log(1/α_sess)` 作为理论参照、`session_p = 1/E`、以及 §4.3 末尾"多 episode 会话按 e 值可加"
这几项**全部失去依据**。DRS 剩下的是——用一个新统计量（贴现累积的校准证据）做的、和 MD3 同一种的
**保形路径极大检验**。作者在失败判据 5 里已经预写了这个结局（"ρ>3 时不得声称 anytime-valid 的好处"），
但把它挂在一个经验量上，而真正的问题是推导本身。

第三点，较轻但要记：`E_t` 是校准分数的**贴现累积和**，形式上就是一个有限记忆 CUSUM。C 列禁的是"用 CUSUM
降 FAR"，DRS 主张的是"同预算换及时性"——这个区分在原则上成立，但 L 的审计原话是"持久性/块/CUSUM
**只移动 ROC 点**"，而 DRS 要的正是移动 ROC 点。所以 DRS 的增量是否落在 C 列之内，取决于"移动到的那个点是否
比冻结候选在同 FAR 下更早"——这恰好是它的 P2 格。设计上自洽，但它比其他三份更接近 C 列边界。

### 2.3 预注册与多重性

4 格、Holm、m=4，副臂明确"不进家族、纯描述"，8 条编号失败判据。**P2（DRS 减 A-only 的配对 McNemar）
是四份提案里最干净的决定性检验**：它直接测量本提案主张的那一件事，并预写"P2 ≤ 0 → 立场 B 被证伪"。
P3 被诚实标注为"设计上就是预期失败的记录格"。§8 风险 6 主动写下 winner's curse
（层带窗宽继承自 36 候选的事后挑选），并声明"**DRS 与 CAND-A 的差值才是本轮的干净证据，绝对数不是**"——
这是四份里最强的一句方法论自律。

功效（Holm 最坏 α=0.0125）：P1 0.71（n≈80）、P2 0.72、P3 0.76、P4 0.99/0.62。诚实。

### 2.4 陷阱检查

| 陷阱 | 判定 |
|---|---|
| 跑遍格子 | **躲开**，副臂显式出家族 |
| ±5 容差 | **躲开**，双锚并列 |
| 未配对延迟 | **踩了**。失败判据 4 是"中位延迟未比同预算 CAND-A 少 ≥2 token"——这是两个命中集合不同的检测器之间的
**未配对**中位数比较，正是 `audit_statistics.md` §7 证明会给出 p=1.000 的那种比较。而且这条判据**没有任何功效声明**。必须改为共同命中集合上的配对差 + 可达性表 |

### 2.5 结论

诊断最锐利（把延迟拆成"99.5 百分位 vs 95 百分位"的距离，并给出可事前否证的算术），ρ 是本轮最好的单个仪器；
但**它命名自己的那个装置在数学上不成立**，且唯一的延迟失败判据踩了本轮明令要躲的陷阱。

## 3. TSSM：两阶段切换–持续状态机

### 3.1 零假设与校准有效性：本轮最诚实的一份

TSSM 不声称 anytime-valid（§10 明写"以经验 held-out FAR 为主张依据，不引用 anytime-valid 的理论保证"）。
它的 `e_s = (1/p̂_s)^{1/w2}` 不是 e 值（`E[(1/p)^{1/8}] = 8/7 > 1`），`logE_k` 只是一个贴现累积和——
但这**不重要**，因为阈值是
`h = N_cal 上每条 routine trace 的 max_k (logE_k − log(1/λ_k)) 的第 ⌈(n+1)(1−α)⌉ 小者`。
统计量可以任意；有效性来自路径极大的次序统计量。TSSM 是四份里唯一没有把"统计量的名字"和"有效性的来源"混为一谈的。

更重要的是它**把整条流水线放进了零分布**：`N_cal` 的每条 routine trace 都跑同一台状态机——同样的 S1 候选生成
（固定速率 ρ=0.02）、同样最多 3 个并行 episode、同样的 λ_k 预算折减——然后取 `max_k(logE_k − log(1/λ_k))`。
于是"S1 不承担 FAR 预算"这句话是**真的**：候选生成的多重性、并行 episode 的多重性、λ 折减，全部被吸收进被校准
的统计量里，而不是靠论证被打发掉。这是四份里对多重性处理最干净的一处，也是本轮最值得整体移植的东西。

其余：`τ_ret` 由 routine trace 内自变异校准；F4 用一个**routine-only 的降级门**处理（候选速率跨批相差 >2×
或概率版/入选率版候选集合 Jaccard <0.5 → 降级为已并列冻结的 top-8 Hellinger 版）；
**拒绝把 192-token 的 C1 阈值外推到 384-token**，另用 B2-384 的 160 条 routine 控制——这一条其他三份都没有做到
同样明确，而它直接来自 B5.16 的删失教训。

**一处契约缺陷**：逐 token 输出 `s_t = max(calibrated(z1), max_k calibrated(logE_k))`。`z1` 是按**固定速率**
ρ=0.02 校准的，不承担 FAR 预算、其零分布语义与第二阶段的保形 p 完全不同；把两者取 max 后作为
"逐 token 校准分数（正常流量上分布已知）"输出，等于把一个未按 FAR 校准的量混进契约 E 要求的那条流。
可修（把 z1 从分数流里拿掉，只作 EVENT 的元数据），但按现文写法它破坏契约。

### 3.2 预注册与多重性：本轮最好

只有 3 个主格，每格一个配置，Holm α'=0.0167。核心特征：

1. **P1 是配对 McNemar，门槛 Δ ≥ +0.12，且门槛值由功效反推**（Δ=0.12 时功效 0.72；Δ=0.08 时 0.40，
   并明写"**B3 不足以判定 0.05–0.08 量级的改进**"）。
2. **"Δ ≤ +0.05 或方向为负 → 声明 no-go，不得改参数重试"**——这一句直接杀死 §2.6 的"跑遍格子"模式，
   是四份里唯一把"不许重试"写进预注册的。
3. **P2 的样本量论证改变了数据要求**：n=120 时观测 6/120 的 Wilson 上界 0.105，**不支持**"≤0.10"的区间主张，
   因此把 held-out routine 要求提到 ≥200。这是"先算功效再定门槛"的正确顺序。
4. **一个专门的候选阶段证伪审计**（一级）：若 ≥30% 的 drift 确认锚定在早于 product_onset 超过 32 token 的候选上，
   **且**同 scenario 的 benign 臂在相同相对位置也会确认，则判 S1 不成立。这是四份里唯一为"检测器响应的是提及
   还是进入"设计的、可事前证伪的机制检验（简报 B3.11 的 RASET 边界至今只被当作免责声明）。
5. **P3 有硬样本门**（`n_resist_terminal ≥ 20`、bounded ≥12），收不齐即预先声明 `inconclusive_sample_support`，
   "不得把'只差一条'改写为通过"——直接照搬 LDC 的先例。

**代价：功效被摊得很薄。** P1 0.72、P3 0.79（真值 0.85 时），而设计里有 ~15 个被冻结的自由度
（LATE/EM 两个带、w1/gap/r1、w2、BMIN/BGAP、ρ、DEDUP、M_max/K_max、λ_k、R_RET、τ_ret 口径、
prior_baseline 通道）。三个格测的是**整捆**，不是机制。而作者自己预测其中两个新机制会失败
（S8 返回事件：15–25% 的执行会被误判为 `resisted_return`；P3 子分类：n_bounded=5 不可评价）。
于是"Δ ≤ +0.05 → 永久 no-go"这条正确的纪律，配上一个不可分解的捆绑，会让一次失败**什么都学不到**。

### 3.3 陷阱检查

| 陷阱 | 判定 |
|---|---|
| 跑遍格子 | **躲开且最彻底**（3 格 + 不许重试 + 备选臂需 Bonferroni ×2 才能升为主张） |
| ±5 容差 | **躲开**。双锚点；容差带写成**非对称**的 `[onset−8, onset)`，`end < onset−8` 仍算误报 |
| 未配对延迟 | **躲开**。P1 是配对召回；次要 (b) 报"不可逆点前触发比例 + token 余量分布"，召回与余量并列；未把命中中位延迟当端点 |

### 3.4 结论

统计纪律与多重性处理是四份之最；把整条流水线放进零分布这一手应当被所有后续设计继承。风险不在有效性，
在**可学习性**：一个 15 参数捆绑 + 一个正确但不可分解的 no-go 规则。

## 4. MD3：最小可部署三通道监视器

### 4.1 零假设与校准有效性：唯一无歧义正确的构造

`Mcal[c]` = 校准池每条 trace 的**整路径最大值**集合；在线
`p[c](t) = (1 + #{m ∈ Mcal[c] : m ≥ smax[c](t)}) / (n_cal+1)`，`smax` 是被评价路径的 running max。
因为 `smax` 单调、参照集固定，`p[c](t)` 在 t 上**单调不增**，于是
`P(∃t : p[c](t) ≤ α) = P(路径极大 ≥ h_c(α)) ≤ α` **精确成立**，且天然 anytime。
四份里只有这一份把逐 token 的 p 值流和路径级保证在同一个构造里对齐，没有留任何缝。
`p_session = min(1, 3·min_c p_c)` 是任意依赖下有效的 Bonferroni，保守但正确。
`confirmed_routing`（两通道 16 token 内同时触发，或 `min p ≤ α/4`）是 OR 事件的子集，因此 FAR ≤ OR 的 FAR，
未破坏预算——虽然它本身没有被单独校准。

**四份里唯一监控自己前提的一份**：§4.4 的漂移监控（滚动 200 条 routine 的超越率二项区间 [0.019,0.078]、
桶 μ/σ 位移门、新 unseen pair 出现率、JSON 占比 ±10pp、长度中位漂移 30%）+ 再校准节奏
（阈值每 200 条或 2 周；`N_fit` 每季度或模型/系统提示变更时强制重拟合）。
保形有效性完全依赖"校准池与在线流量可交换"，而简报 B2.6 已经证明这个前提**在同一批数据的两半之间就已经被违反**；
只有 MD3 给了一个持续测量它的仪器。同理，次族里的
**"C1-校准 vs B3-自校准的运行点差 > 0.10 → 阈值不能出厂"** 是本轮最有部署决策价值的单个测量，
而且它是同一批 trace 上的配对比较，功效高、成本近零。

**两处扣分**：
1. **两半带符号差 ≤0.10 没有进主族**（§4.2 只作要求与报告）。TCD 的格 C、DRS 的失败判据 1、TSSM 的 P2 都把它
   写进了主格。鉴于 B2.6 的符号差是系统性的（16 格中 15 格同号，阈值比 1.40–1.47），这一项应当是门而不是报告项。
2. **位置桶用"每桶 ≥30 个窗口"而不是"≥30 条 trace"**（§4.2 明写并给了理由）。窗口数达标但只来自 2 条 trace 的
   桶，其 μ/σ 与"运行点由 4 条 trace 决定"是同一个病。"定阈者透明化 + 剔除 top-1/3/5"覆盖了阈值那一侧，
   没有覆盖桶统计量这一侧。

### 4.2 预注册与多重性

3 个主格（Holm）+ 一个长次族（BH，明确非门）。功效计算规范：
P1（R+16 ≥0.55，n=100）功效 ≈0.90、CI 半宽 ±0.10；P2（FAR ≤0.15，n=200）Wilson 上界 0.147；
P3（代码 n=20，真值 0.75）精确二项功效 ≈0.85。**四份里唯一在主族三格都达到 ≥0.85 功效的**——
因为它测的是绝对水平而不是增量。

**最好的一处**：§5.2 的"失败判据（写死的解释规则）"表——每一种失败预先绑定一个**结论**
（P1<0.40 → 是表示问题不是校准问题；P2 超标且 JSON 差 >0.10 → 适用范围收缩；P2 超标但集中在最长三分位 →
判为长度暴露、**不启用长度分层阈值**；T 误报 >0.02 → 代码域写入不可检；剖面 CI 跨 0 → 该字段从输出中删除）。
这是四份里唯一把"失败之后做什么"也预注册了的，直接对治 fcm/narrow_window 两轮"失败后改判据"的风险。
另外"JSON vs 非 JSON 各 90 条检出 0.10 差的功效只有 0.45 → 预注册为**范围收缩触发器**而非显著性声明"
是一个功效驱动的正确降级。

**最大的预注册缺口**：MD3 的实质主张是"三通道 OR 相对单个冻结候选买到 +8 召回 +0.10、延迟 8→5"，
但**主族里没有任何配对增量检验**。P1 是一个绝对门槛，单通道 A 也可能通过或不通过；MD3 完全可能"通过 P1"
而从未证明 OR 值得它付出的 α 拆分。TCD 的 D、DRS 的 P2、TSSM 的 P1 都把这个配对增量放进了确认性家族。
建议把"OR vs A-only 的配对 McNemar（R+16 与 R+8）"提为第四主格。

### 4.3 陷阱检查

| 陷阱 | 判定 |
|---|---|
| 跑遍格子 | **躲开**。3 主格 + 次族 BH + 明确非门；次族条目多（14 项）但每项都有预写的解释规则 |
| ±5 容差 | **躲开**。双锚，"容差带按两锚之差定" |
| 未配对延迟 | **部分躲开**。"命中中位延迟（与 recall 并列）"在次族里；没有配对要求，也没有可达性/删失表。既然 MD3 的卖点里包含"延迟 8→5"，这一项必须配对 |

### 4.4 结论

统计上最保守、最正确、最可运维的一份；它的弱点不在有效性而在**野心**：主族测的是绝对水平，
所以它可以通过而不证明自己的增量；及时性明确放弃。

## 5. 四份共同的问题

1. **"两半可交换"这个已知被违反的前提**。B2.6 记录的是**系统符号差**，不是随机抖动。三份把 ≤0.10 写进了主格
   （TCD-C、DRS-1、TSSM-P2），MD3 只作报告。但没有任何一份说明：**如果两半差超线，α 的声明该怎么改写**。
   正确做法是预写一条"两半差 > 0.10 → 主表的 α 只能声称为经验 FAR，不得称为保形保证"的降级规则。
2. **位置桶的契约张力四种处置**：TCD（有桶为主 + 预注册无桶消融）、DRS（把桶重解释为"已进行的检验次数"即
   risk clock，并把整条解读单列请组长追认 + 无桶副臂）、TSSM（桶只进 S1 速率校准，承担判定的第二阶段完全
   age-free）、MD3（主格保留 + bucket-free 单格，若无差异则 v3.1 删桶）。
   **DRS 的处理最诚实**（把它标为需要裁决的契约解读而不是自行决定），**TSSM 的处理最彻底**
   （把 age 隔离在不承担预算的那一半）。这四种应当合并成一个**统一的判决单格**，而不是四份各做一次。
3. **代码域的"领先时间"都是条件于双命中的量**。TCD 的"provisional 领先 ≥8 token"、DRS 的"路由 provisional +
   T2 文本 confirm 的中位延迟"、MD3 的 P3、TSSM 的 (c)，都只在同时被路由与文本命中的样本上定义。
   必须同时给出 provisional 自身在该运行点上的 LR+，否则一个 α_prov=0.25 的 provisional"领先 17 token"没有信息。
4. **没有一份预注册配对延迟检验**。四份都记得"召回与延迟并列"，但只有 TSSM 完全避开了把中位延迟当端点；
   DRS 甚至把未配对中位延迟写成了失败判据。B3 应统一要求：延迟只在共同命中集合上配对报告，并附
   `audit_statistics.md` §8 那种可达性/删失表。

## 6. 评分

标度：1–5，cost 5 = 最便宜。评分口径为**统计有效性与可预注册性**透镜。

| | consistency | avoids_dead | earliness | far_control | fusion_ready | prereg_power | cost | **total** |
|---|---|---|---|---|---|---|---|---|
| **MD3** | 5 | 5 | 2 | 5 | 5 | 4 | 5 | **31** |
| **TSSM** | 5 | 4 | 3 | 4 | 3 | 5 | 3 | **27** |
| **TCD** | 5 | 4 | 3 | 3 | 4 | 4 | 4 | **27** |
| **DRS** | 4 | 3 | 4 | 3 | 3 | 4 | 4 | **25** |

评分要点（只列偏离直觉的）：
- **far_controllability**：MD3 5（构造无歧义正确 + 唯一监控前提）；TSSM 4（流水线整体入零分布，但不声称理论保证、
  且分数流混入未按 FAR 校准的 z1）；TCD 3（p 值构造两种写法互斥、删失方向自评写反）；
  DRS 3（e-process 推导不成立，实际保证退回保形路径极大，且 α_sess=0.05 更紧但没有额外机制支撑）。
- **prereg_power**：TSSM 5（门槛由功效反推 + 不许重试 + 样本量论证改写数据要求 + 候选阶段证伪审计）；
  TCD/DRS/MD3 各 4，扣分点分别是主次序放反、未配对延迟判据、缺配对增量格。
- **expected_earliness**：按各自的**自我预测**而非主张打分。DRS 4（R+8 0.35–0.45、中位 5–8，且给了可事前否证的
  百分位算术）；TCD 3（自认"分解不改变裕度"，只有 J 的 w=4 值 2–3 token）；TSSM 3（1–2 token 余量，
  且 λ_k 把后段候选推得更晚）；MD3 2（明确放弃）。
- **fusion_readiness**：MD3 5（四条校准 p 流 + 可重分配 α + 剩余预算 + 版本号，正是"多信号之一"需要的）；
  TCD 4（对外只给一个融合 p 与 argmax 通道，下游无法重加权）；DRS/TSSM 3（单一累积统计量 / 分数流语义混合）。

**排名（本透镜）：MD3 > TSSM > TCD > DRS。**
MD3 与 TSSM/TCD 之间的差距主要来自"零假设下校准是否真的有效"这一条；TSSM 与 TCD 同分，
按本透镜的第一顺位（预注册与多重性）TSSM 在前。DRS 垫底不是因为想法差——它的诊断和 ρ 是本轮最好的——
而是因为它给自己命名的那个统计装置在数学上不成立，且唯一的延迟失败判据踩了本轮明令要躲的陷阱。

### 致命缺陷与可移植的最佳想法

| 提案 | 致命缺陷 | 最该嫁接的想法 |
|---|---|---|
| MD3 | 无致命缺陷。最接近的一条：全部主张的增量（OR 相对单通道的 +0.10 召回、延迟 8→5）**没有任何确认性配对检验**，P1 是绝对门槛，MD3 可以通过 P1 而从未证明三通道值得它的 α 拆分 | **整路径极大次序统计量作为参照集的单调 p 值流**（running max vs 全路径 max 集合）——四份里唯一逐 token 与路径级保证严格对齐的构造；外加流形漂移监控 + 再校准节奏，以及"C1-校准 vs 自校准运行点差 >0.10 → 阈值不能出厂"这一格 |
| TSSM | 三个主格测的是一个 ~15 参数的捆绑，作者自己预测其中两个新机制（S8 返回事件、P3 子分类）会失败；配上正确的"Δ≤+0.05 即永久 no-go、不得改参数重试"规则，一次失败在机制上**不可归因**——证伪了什么无法辨认 | **把整条流水线放进零分布**：让每条 routine 校准 trace 跑同一台状态机（同样的候选速率、同样的并行 episode、同样的 λ_k 折减），阈值取 `max_k(logE_k − log(1/λ_k))` 的次序统计量——候选选择与 episode 多重性被吸收进被校准的统计量而不是靠论证打发；外加"候选阶段是否在响应'提及'"的可证伪审计与"不得改参数重试"条款 |
| TCD | 无致命缺陷但有一处必须修的硬伤：核心有效性声明被写成两种互不相容的形式（§2 的逐 look 风险时钟参照集 vs §5 的固定路径极大阈值），只有后者成立；且 §10 把 carry-forward 删失的方向判反——它对长 trace 是**反保守**的，正好作用在 FAR 0.206 的最长三分位 | **按 routine 方差/频率把坐标严格二分**（Ω_rare / Ω_freq + 方差地板），让"支持集内重排"拿到自己的零分布而不是被淹在同一个标量里；**边际校正的联合新颖度** `−log[P(a,b)/P(a)P(b)]`（扣掉 79% 的边缘机会）；**`R_p` 的 routine-only 跨半稳定性门**（不看任何正例地回答 F4，通不过就写"F4 = 否"） |
| DRS | e-process 不是 e-process：`e^A·e^R` 是同一 look、重叠窗口上两个强相关 e 值的乘积，任意依赖下不是 e 值（TCD 正因此选了算术平均）；且"shrink(x) ≤ x ⇒ E_t ≤ M_t 逐路径"的论证漏掉了 γ 指数（x<1 时 x^γ > x）。Ville 界、`session_p = 1/E`、跨 episode 的 e 值可加性全部失去依据，实际保证退回到与 MD3 同款的保形路径极大 | **ρ = h_conf / log(1/α) 作为一级测量的相依性罚项 + 预注册失败线**，把"重叠窗口不是独立样本"从告诫变成一个数；以及**把延迟拆成"窗宽 + 裕度"、把裕度量化为"99.5 百分位 vs 95 百分位"的距离**这套可事前否证的算术，和 §8 风险 6 的"只有差值是干净证据、绝对数不是"这条自律 |

## 7. 如果只能造一个检测器

**骨架用 MD3，统计量用 TCD 的三通道，校准协议用 TSSM 的整流水线保形，仪器用 DRS 的 ρ。**

**取自 MD3（保留全部）**
- 参照集 = 校准池每条 trace 的**整路径最大值**；在线 p = running max 在该集合中的秩。单调 ⇒ 逐 token 流与
  每 episode "曾报警" 保证严格对齐，不需要任何 e 值理论。这是唯一一个四份都能安全共用的有效性基座。
- 输出契约：三到四条**独立校准的 p 值流** + 证据窗 + 归因通道与坐标 + provisional/confirmed + **剩余预算 + 版本号**。
  不在检测器内部把它们塌成一个数（这也是"多信号之一"的部署定位所要求的）。
- §4.4 的漂移监控与再校准节奏，以及"C1-校准 vs 自校准运行点差 > 0.10 → 阈值不能出厂"这一格。

**取自 TCD（取表示，不取校准）**
- 通道 S/R/J 的坐标划分：稀有坐标的 −log q（S）、频繁坐标上的白化能量 + 方差地板（R，主路径只用入选指示）、
  边际校正的相邻层 top-1 耦合（J）。这三个量替换 MD3 的 S/A/B，因为它们是**构造上互补**的，
  Bonferroni 的保守性在互补通道上比在共享同一白化坐标的 A/B 上小得多。
- e 值算术平均只作为**次级融合读数**（任意依赖下有效），主读数仍是每通道自己的路径极大 p + Bonferroni。
- `R_p` 的 routine-only 跨半稳定性门原样保留。

**取自 TSSM（取协议与纪律）**
- **每条 routine 校准 trace 必须跑与在线完全相同的流水线**，包括任何候选生成、任何并行状态、任何预算折减；
  阈值取该完整统计量的路径极大次序统计量。凡是在线会做的事，零分布里必须也做。
- 预注册纪律：门槛值由功效反推；"Δ ≤ x → no-go，不得改参数重试"；样本量不足即声明
  `inconclusive_sample_support`；拒绝把 192-token 阈值外推到 384-token。
- **候选/归因阶段的证伪审计**：报警相对 product_onset 的 offset 分布 + benign 臂在相同相对位置的报警率。
  这是目前唯一能把"响应进入"与"响应提及"分开的可事前证伪检验，必须进主表。

**取自 DRS（只取仪器与自律）**
- ρ = 实测保形阈值 / 理论界，作为一级报告量与预注册失败线；即使不用 e-process，也用它报告
  "重叠 look 的有效独立数"。
- 延迟 = 窗宽 + 裕度的分解，以及"只有相对冻结候选的**配对差**是干净证据"这条写进方法的自律。

**明确丢弃**
- DRS 的 e-process 品牌与乘积合并（`e^A·e^R`）、Ville 界、`session_p = 1/E`、跨 episode 的 e 值可加。
  贴现累积统计量本身可以保留，但只能作为**一个预注册副臂的统计量**，由同一套保形路径极大定阈，不得引用 anytime 理论。
- TCD 的逐 look 风险时钟参照集与 carry-forward 删失（改为固定路径极大阈值），以及 §2 末的子分类
  `mean z[+32..+63] − mean z[+0..+15]`（形式上仍是被证伪的固定 64-token delta）。
- TSSM 的返回事件状态机（S8）、在线抵御/执行子分类、以及基于 router 概率的 S1（F4 风险 + 契约上概率只该进证据载荷）；
  并行 episode 的**架构**可以留，λ_k=2^-k 的陡峭衰减应换成更平的分配或直接由路径极大统计量吸收。
- MD3 的 `confirmed_routing` 临时规则（"两通道 16 token 内 或 min p ≤ α/4"）——改成一个被单独校准的联合统计量；
  以及"两半带符号差只作报告"的处理，改为主格门。

**主族只留四格**（Holm，family α=0.05；每格一个写死的配置）：
1. **增量（决定性）**：三通道 OR/融合 vs 冻结 CAND-A 单通道，同一 FAR 工作点，配对 McNemar，端点 R+16 与 R+8；
   门槛由功效反推（n=100 主事件正例时约能检出 Δ=0.12）。
2. **风险**：held-out routine ≥200 条上的每 episode FAR ≤0.15（Wilson 上界 ≤0.20），
   **且两半带符号差 ≤0.10**（超线则主表降级为"经验 FAR"，α 声明作废）。
3. **配对延迟**：共同命中集合上的延迟配对差 + 可达性/删失表；不报未配对中位数。
4. **代码域（scoped）**：route-only 与 route+text 分列，同时报告 provisional 自身在该运行点的 LR+。
