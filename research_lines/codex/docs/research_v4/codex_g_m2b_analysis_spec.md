# Codex G / M2-B：连续路由信息的概率分解

日期：2026-09-08 UTC。状态：读本轮新统计量前固定的开发分析规范，**不是G-conf预注册或检测器评价**。承接[M2-A报告](codex_g_m2a_report.md)，不预设权重胜出，不修改原匹配。

## 1. 问题与恒等式

P的后层差异究竟依赖实际入选集合内的配比、已选集合的总概率质量，还是未入选专家的相对偏好？先定位固定读出的信息来源，不将表示消融当作干预模型的因果实验。

对每个token/层，A为缓存的实际top-4专家，U为A内均匀分布，R为其余28个专家的均匀分布。P仍是float32的全32专家softmax。定义

`m = sum(P[A]); V = P·1_A/m; Q = P·1_not_A/(1-m); P = m V + (1-m) Q`。

V是从存储logits重建的条件分布，W是实际缓存门控；两者可能因降精度略有不同，不将V冒称W，不重新top-k。验证概率恒等式、单纯形及V/W重建误差；m或1−m数值为零时停止报告异常，不静默填补。

## 2. 固定表示与读出

保留M1的U/W/P，并增加5个表示：

| 名称 | 定义 | 被移除的信息 |
|---|---|---|
| V | 已选条件概率 | 仅用于隔离W与重建值的数值差异 |
| P_no_mass | m0 V + (1−m0) Q | 当前token已选总质量的变化 |
| P_no_selected | m U + (1−m) Q | 已选集合内部配比 |
| P_no_tail | m V + (1−m) R | 未入选集合内部配比 |
| P_support_mass | m U + (1−m) R | 两侧内部配比，只保留实际集合及其质量 |

m0是**不含目标折**的质量通过正常拟合折的逐通道、逐层token加权平均m；不是0.5等任意常数，也不来自攻击或事件窗口。它保留正常的层/通道尺度，但固定token间的质量变化。所有消融的正常参考分布也按对应表示在同一拟合池计算；P_no_mass的q可用m0与正常V/Q均值线性组合，其他表示不能用均值乘积代替逐token乘积的均值。

沿用V1/message、w8因果通道窗、全24层、H352 looks、fixture_rank_mod三折k评价/k+1拟合/k+2正常参照，以及M1的百分位桶、回退门槛和顺序。新增表示独立校准百分位，不修改原U/W/P分数；回算原U/W/P raw JS与q，核对原网格及参考回退。前/中/后各8层全部报告，不选最优层。

主要效应是原P残差减各消融残差（正值表示移除信息后该固定读出的分离减弱），同时报告每种表示的原始JS及百分位水平、残差和前后差分。V−W作为存储精度检查。**消融的差异不相加，不解释成条件互信息、因果贡献、实测FAR匹配或检测增益**；重新归一化与非线性读出可能让移除信息反而扩大分离。

## 4. 集合不变时的动态分解（辅助描述）

仅在相邻token同message通道、同Agent step、实际专家集合相同的层上计算；排除首token、边界和集合变化。对P_t、P_(t−1)按共同A精确分解JS：

`JS_total = JS_Bernoulli(m_t,m_prev) + JS_selected_contribution + JS_tail_contribution`。

后两项是各组混合质量乘以相应条件分布的广义加权JS，而不是简单的m×普通JS。验证逐层非负及加和误差；合成测试分别只改变质量、已选配比和尾部分布，检查只激活预期分量。

动态读数在原H内合格look**端点**上取相邻token对，不是M1窗口均值对参考的JS，不能当作其精确分解。只作全G-dev/阶段描述，不以动态可用性重新匹配donor。各episode/层带先在可用pair上求均值，再episode等权；报告pair数、稳定集合占比和无可用pair的episode数，缺失不记零。份额只在同一有效分母的分量均值之和上计算，不平均逐pair的比例。
