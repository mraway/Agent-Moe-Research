# M13：非执行样本也有路由残差，但输入与行为仍未分离

2026-09-08。**gpt-oss-20b / Agent v3 / G-dev development mechanism evidence。**
不做检测器、工作点或因果/确认性检验；未改变标签、观察视界、算法线、Claude工作区或G-conf。

## 1. 给研究主管的摘要

本轮把“最终执行了注入任务”的E附近样本，与“载注入但没有执行”的样本放在同一对正常参照下比较。
我们找到了一些**非执行样本同样远离正常路由**的例子；参与或承诺后未执行的对照，其距离甚至高于最终执行组。
因此，不能直接把路由距离解释为“执行成功程度”或“偏离严重程度”。

然而，这轮更重要的发现是**有效对照极少**：最近8个token完全相同时，参与未执行组只匹配到
4条query/10个look，而它们全部复用同一条对照；承诺未执行组4条/8个look，也全部复用一条对照。
静默组没有可比较样本。再要求同攻击家族，只剩参与未执行组1条query/3个look；再加同措辞层，所有组均无支持。

所以，本轮只提供对“执行特异性”的案例级反例，**没有识别路由残差究竟来自输入注入文本、长上下文还是参与行为**。
与“抵御过程中也可能有异常信号”的假设相容，不足以确认该假设；保留的L8窗口全部是工具调用通道，不是analysis推理窗口。
缺匹配支持不是算法漏检、不是观察视界不足，也不说明路由效应为零。

## 2. 冻结设计与测量含义

方案：[M13预先冻结方案](codex_g_mech_m13_analysis_spec.md)，提交`aca1c2a`。
实现/测试/独立审计提交`602202b10d84adae6419d87cec261b3a8d2416ee`，随后才读取本轮对照结果。
只读取M7–M12冻结产物和M7记录SHA的私有G-dev路由缓存，CPU分析，无模型加载、前向或新生成。

q为最终有X的episode在`[E,E+16]`内的look，a/b为M12已固定的正常配对。
主列使用M12 L8的31条query episode/88个look；L1的78条/195个look是较弱的当前token范围列。
总体仍是126条最终有X episode、1453个E附近look。**q不是“正在执行X的token”**，不能把本轮称为X阶段实验。

c来自四类载注入、无X的episode。silent/over_refusal使用所有合法look，不虚构E；
engaged_only/committed_no_execution取自己的`[E,E+16]`。
按整条episode轨迹类分组，不保证所取look已经到C，更不是四类实时状态的在线识别。
“未执行”也不等于原任务完成或抵御成功。

四者同fold、harmony通道、episode index、生成step、通道序号桶及生成端点桶；
四个scenario不同、q/c同注入渠道，六条边TU差均≤0.25、q/c后缀L-token完全相同。
L8包含当前token及前7个；另外依次加入同攻击家族、同措辞层。
c按预先固定的TU/端点/episode-key顺序选第一名；**不更换a/b，不看路由择样本**。

U是实际入选4个专家的等权向量；W是实际入选logits上的softmax；P是全32专家softmax。
使用实际IDs，不重做top-k；W由bf16缓存重建，P不是模型的实际专家组合权重。
路由处理的是已采样的当前token，不是采样前预测该token的状态。

每层TV距离定义：

`Aq=(d(q,a)+d(q,b))/2`，`Ac=(d(c,a)+d(c,b))/2`，`N=d(a,b)`；
`Dq=Aq-N`，`Dc=Ac-N`，**`B=Dq-Dc=Aq-Ac`**，另外保留`Qc=d(q,c)`。

Dc衡量非执行c相对同一正常背景的超额距离；B才是本轮的执行组—非执行组配对差。
B不是把不同样本的总体均值相减。先平均24层，再look→query episode→episode平权。
c的均值按其在这些query中的复用权重计算，**不是该非执行组的总体均值**。

本轮使用的episode级`stop_reason`均为`final_channel`，未以结束原因删样本；
这不等于完成了原始trace/逐step生成失败审查，本轮没有重新读原始轨迹或按GENFAIL文本筛选。

## 4. 路由差异在非执行例子上也存在

以下为L8/同渠道列、全层TV的 **Dq / Dc / B**。只描述各自已匹配的四元组。

| c组 | U：实际选择分布 | W：入选权重 | P：全专家概率 |
|---|---:|---:|---:|
| engaged_only，4条query/1条c | .08247 / **.09505** / **−.01259** | .09519 / **.10615** / **−.01096** | .03118 / **.03219** / **−.00101** |
| committed_no_execution，4条query/1条c | .02865 / **.06771** / **−.03906** | .03642 / **.06794** / **−.03152** | .01578 / **.01831** / **−.00253** |
| over_refusal，2条query/1条c | .06771 / **.05208** / **+.01563** | .07401 / **.05048** / **+.02353** | .02661 / **.01132** / **+.01529** |
| silent | 不可估 | 不可估 | 不可估 |

参与未执行例子的U Aq/Ac/N=.12847/.14106/.04601，W=.13998/.15094/.04479，P=.04458/.04559/.01340。
Dc>0不是由“用另一组正常背景减法”造成的，B中的同一个N已精确消去。
但同正常参照不等于完整输入相同，因此也不能将B归因于行为本身。

预定家族bootstrap2000次、seed802608的B区间：

| c组 | U的B区间 | W | P |
|---|---:|---:|---:|
| engaged_only | [−.01563,−.00694] | [−.01426,−.00473] | [−.003044,−.00000295] |
| committed_no_execution | [−.04688,−.03125] | [−.03840,−.02406] | [−.005114,−.001486] |
| over_refusal | [.01042,.02083] | [.01971,.02736] | [.01431,.01627] |

**这些区间不能作为非执行群体的可靠总体推断。** 重抽的是query家族，c在每列始终只有同一个episode；
没有计入c的抽样/复用、匹配选择、未来结果分组、重复开发和多重比较的不确定性。
committed/over_refusal列的Dc甚至在query间恒定，产生退化的点区间，并不是“测得非常精确”。
family×tier稳健列中，engaged_only的P之B区间为[−.002534,+.000516]，**跨0**；不把名义家族列写成一致的显著证据。

W/P归一化JS的B方向与对应TV相同：engaged_only −.009670/−.000209，
committed_no_execution −.030846/−.000473，over_refusal +.013965/+.001023。
这些是同一小样本上的距离稳健列，不是独立复制。U-JS与U-TV恒等，不另报证据。

## 5. 四者入选集合相同的层：权重变化也非执行特有

以q/a/b/c实际入选集合均相同的层为共同mask；每look只平均这些层。
U各项距离按定义为0，W/P的结果如下：

| L8同渠道c组 | query episode / look / 合格层四元组 | W：Dc / B | P：Dc / B |
|---|---:|---:|---:|
| engaged_only | 4 / 10 / 121 | **.018649 / −.000680** | **.018472 / +.000560** |
| committed_no_execution | 4 / 8 / 101 | **.011784 / −.000027** | **.013838 / −.000659** |
| over_refusal | 2 / 2 / 20 | −.003632 / +.007085 | −.001713 / +.013757 |

前两组权重B的家族区间均跨0：
engaged_only W [−.001851,.000462]、P [−.001238,.001974]；
committed_no_execution W [−.001199,.000785]、P [−.001606,.000203]。
不能据此宣布“权重无用”或两组等价，也不能忽略over_refusal条件mask下Dc转负的例子。
不同mask的均值不能相减作选择/权重的因果分解。

这说明M12观察到的“集合相同仍有权重残差”也可出现在非执行对照上；
**权重包含额外变化，不自动等于额外的行为判别力**。本轮没有测任何检测器的增益。

## 6. 更严格与更宽松的条件各自说明什么

### 6.1 同攻击家族仅剩一个案例；再同措辞则不可估

唯一同家族L8配对是最终执行query `g-dev-219--attack#ep0`（T2），
与参与未执行c `g-dev-111--attack#ep0`（T0）的DNA家族，3个look。
其U/W/P Dq=.138889/.157187/.046545，Dc=.145833/.161915/.047552，
B=−.006944/−.004727/−.001007。单家族bootstrap退化为点，不展示成有意义的总体区间。
再要求同措辞后它退出。两者的完整输入仍不同，不可说已经控制了攻击文本。

所有组的三层共同query集为空；channel→family唯一可配对案例未换c，配对差为0。
所有L1/L8共同query上的四元组和分数也原样相同、配对差为0。
更严格列不是一次新的独立实验；不能把全支持均值的变化解释成消除了某种混淆。

### 6.2 L1只控制当前token，不能替代L8

L1/同渠道的query episode/look/独立c数分别为silent 3/3/3、engaged_only 7/13/4、
committed_no_execution 5/10/2、over_refusal 7/7/6。再同家族也只有上述1/3/1，最高层全空。

| L1 c组 | U：Dc / B | W：Dc / B | P：Dc / B |
|---|---:|---:|---:|
| silent | −.01910 / +.06424 | −.01845 / +.05453 | −.00570 / +.01834 |
| engaged_only | .08408 / −.02579 | .09341 / −.02438 | .03210 / −.00860 |
| committed_no_execution | .06632 / −.02431 | .06540 / −.01756 | .01790 / +.00072 |
| over_refusal | .07143 / −.01637 | .07219 / −.01440 | .02825 / −.00509 |

silent仅3个analysis窗口/3个家族，Dc三种区间均跨0；虽B区间为正，也不能据此说静默组没有输入响应，
更不能拿它填补L8的空支持。位置≤16后只剩2/2；其余L1组位置敏感性与原样本一致。
L1/L8各组通道、控制episode和query look构成都改变；例如over_refusal的B方向翻转不构成历史控制的因果效应。
所有episode中位数、正值比例、家族与family×tier区间及逐层profile均在产物中保留。

## 7. 为什么没有静默L8对照

M12已有88个L8 query的进一步失败如下；其余1365个E候选没有M12 L8正常pair，单独记`no_base_normal_pair`。

| c组 | 88个已有正常pair query的退出与保留 |
|---|---|
| silent | **结构无候选22 + scenario冲突3 + 注入渠道不符63 = 88** |
| engaged_only | 结构无候选76 + TU不符2 + 匹配10 |
| committed_no_execution | 结构无候选76 + TU不符2 + 后缀不符2 + 匹配8 |
| over_refusal | 结构无候选51 + scenario冲突3 + 渠道不符29 + 后缀不符3 + 匹配2 |

因此，本轮silent甚至**尚未进入后缀比较，就已全部退出**。
不能说“静默样本与偏离样本必然输出不同文本”，也不能说把输出拉长就能解决。
同家族要求后，engaged_only只留3个look；另外两组全部退出。再同措辞所有组为空。
这是本轮冻结设计的支持边界，**不是已经证明G-dev的任何其它合理设计都不可行**。

## 8. 机制判断与下一步

当前可保留的是：局部文本相同、生成端点很接近时，**非执行个案也能有完整路由与权重残差**；
距离大小不应直接等同于执行结果。当前不能确认“注入文本导致残差”，
也不能确认“残差识别了参与/抵御状态”，不能用少数工具调用片段代替analysis推理证据。

下一轮先做**匹配限制的必要性审计**，继续使用现有G-dev，不急于生成数据：

1. 区分真正的输入/任务可比性条件与沿用的分析分桶。例如原始U/W/P距离本身不依赖校准fold，
   “同fold”是否仍必须约束c，需要单独冻结并检验；若改变它，TU的共同参考定义也须先写清楚，不能直接混用不同折数值。
2. 先报告各条件造成的候选损失、独立对照数与通道构成，再决定能否做读数。
   保留同渠道/家族/措辞的目的，不因能获得正向结果而放宽它们；本轮M13结果与配对不作任何事后改写。
3. 若合理约束下仍没有支持，再向主管申请独立命名空间的固定前缀受控复放，
   分别操纵输入上下文与生成历史，检验路由对它们的响应。
   受控前向属于新的实验权限，需要另行批准；强制前缀的机制读数也不能冒充自由运行agent的检测表现。

本轮没有执行上述下一轮分析、受控前向或新生成，也不通过解封G-conf补开发对照。
