# 机制M9：同一个常用token上的路由差异，并非仅来自窗口混合

2026-09-08。**GPT-OSS-20B / Agent v3 / G-dev development mechanism evidence。非确认性、非因果结论。**
依据[主对话机制线分工](codex_g_mechanism_workstream.md)，本轮不设计检测器、不改阈值、不比较新recall/FAR。

## 1. 本轮确实推进了什么

M8的一个替代解释是：虽然当前token相同，但S/CW平均了8个token，差异可能完全来自前7个未匹配token。
**这个“完全由窗口混合造成”的解释，不符合本轮主描述子集的观测。**

- 在原28条episode、45个X窗口上，单独读取身份已匹配的当前token，S差为
  **+36.12，家族95%描述性CI [15.13,78.59]**；CW差为**+50.00 [20.89,111.97]**。
  二者都有26/28条episode为正，中位数18.16/24.86，并非仅一个大离群值。
- 当前token主要是`the`、`a`、逗号等常用成分，而非题外领域专属词。
  因此不能用“只有新出现的领域关键词调用稀有专家”概括这些观测。
- 同token差异主要落在**中层和后层**，不是“越往后必然越强”：当前S差的前/中/后段为3.03/22.22/10.87。
  但S的rare mask本来就更集中于中层，不能把这张分解表当成语义计算发生位置的因果证明。

本轮得到的是**同token、不同生成上下文下的稀有专家调用差异**这一局部现象；
仍有精确位置、语法邻域、体裁、完整上下文等混淆。没有证明“任务意图编码”或“授权识别”。
匹配覆盖仍仅45/2,142个X窗口（2.10%），28/126条episode；M8的共同支持缺口没有消失。

## 2. 首先核查token与路由的时序

采集链为`src/agent_v3/episode.py:_generate_step → src/phase_a/generation.py:generate_routed_turn`
与`src/routing/capture.py:record_step`：

`采样y_t → 记入生成序列 → 以y_t为输入forward并记录R_t → 从该forward的logits采样y_(t+1)`。

因此缓存R_t是**处理已经采样出的y_t**的路由，而不是“产生y_t之前”的状态。
loader会核验缓存token IDs与生成事件的序列逐位一致；本轮合成调用顺序测试另作了重放。
这不表示监测不能在线，也不判断token实际何时发送给用户；只禁止把R_t偷换成y_t采样前的提前证据。
M7已有首报/X窗口结果完全保留，没有因这个说明移动锚点、改分母或重算性能。

## 3. 精确分解：当前token与前7个token各贡献多少

[M9方案](codex_g_mech_m9_analysis_spec.md)先提交于`95f53e4`；实现与独立审计冻结于
`75cd70cd8b0f931b6d17f354967fa4e6dbe0ab00`，首次数据访问前156项合成/回归测试通过，其中新增13项。
复用M8全部72格的原始匹配图、donor顺序与权重；**没有重新匹配、按分数筛选或挑层**。

S逐token逐层贡献为已选稀有专家的−log q之和；CW为这些项乘以既有相对top-k阈值余量因子。
q、rare mask和CW参数都来自M7冻结状态。重建实际top-k和已存logits，不重排、不拟合。
差值先在query episode内平均，再episode平权；全部CI使用query家族2000次聚类bootstrap，另有family×tier列。
均条件于固定匹配图及donor银行，未计donor不确定性、反复开发或多重比较；不作确认性显著性宣告。

主描述列为X / 合格正常 / L1：

|---|---:|---:|
| 当前token的原始差，未除8 | 36.1180 | 50.0013 |

逐look和汇总均满足“当前贡献+历史贡献=原窗口差”。前7个位置的总贡献更大，
**并不等于当前token没有信号**：当前只占8个位置中的一个，还被除以8。
上述比例不是解释方差、因果份额或算法性能提升；不能据它说“84%都是词汇混淆”。

≥3 donor子集仍只有5条/7个look，当前差60.69/85.93，区间很宽，不能借它扩大总体结论。
这些子集不同，不把均值之间的差当成条件控制的解释量。

|---|---:|---:|
| 0–7 | 3.03 [-.17,11.30] | 4.62 [-.14,17.39] |
| 8–15 | 22.22 [11.40,44.56] | 29.08 [14.75,59.10] |
| 16–23 | 10.87 [2.87,23.18] | 16.30 [5.13,35.59] |

完整窗口的S三带贡献为1.87/16.99/9.37，CW为2.49/21.64/13.27。
完整24层profile与区间已保存；没有把某个峰值层升级为新统计量。

**事后为解释层图而读取的冻结q元数据，不是新增检验：**
三折rare坐标在前/中/后带的数量分别为32/70/35、32/69/31、32/69/31。
第0层在三折均没有rare坐标，因此S/CW在该层恒为0，不能据此宣布“第0层没有上下文信息”。

后续需要相同测量下的正常—正常变异基线，才能判断这一层分布是否为任务偏移所特有。

## 5. “相同token”具体是什么

45张说明卡全部保存，按episode key、端点排序，不按差值选例。
当前token只有11种ID，其中` the`15次、` a`9次、逗号9次；加上` of`和` A`，
含字母类26个窗口**全部是这些常用功能词**。没有special token。

| 自动词汇类别 | query episode数 / look数 | 当前S差 | 当前CW差 |
|---|---:|---:|---:|
| 含字母 | 21 / 26 | 46.13 [19.15,102.68] | 64.00 [26.39,146.58] |
| 标点/符号 | 11 / 15 | 14.66 [6.60,20.48] | 19.17 [8.80,26.28] |
| 纯空白 | 3 / 3 | 9.01，单家族 | 11.42，单家族 |
| 含数字 | 1 / 1 | −5.75，单例 | −5.75，单例 |

类别episode可以重叠，不能将各行episode数或均值直接相加。空白的单家族bootstrap退化为零宽区间，
不是高度确定；数字单例为负，不能说所有共享token都上升。类别是描述性读数，不是领域/格式检测规则。

说明卡中第一个` the`查询是`g-dev-011--attack#ep0`的155位置，前缀处于卫星独白创作；
donor在退款政策说明里使用同一token，当前S差42.98。这个例子说明“相同词条≠相同上下文”，
不证明路由辨认了独白任务是否得到授权。45张卡保留8-token文本及截至当前的最多32-token同step前缀，
不包含未来文本；未据人工阅读修改任何标注、匹配或分数。

相同L1匹配下的**当前token原始差**，不是M8的窗口z，也不是提前检出率：

| E / 合格正常 | 104 / 337 | .642 [-.023,1.292] | .755 [.016,1.533] |

| X / 合格正常 | 28 / 45 | 36.118 [15.129,78.589] | 50.001 [20.895,111.971] |

E原始差很小，S区间跨0、正差仅54/104；CW的窄正下界不能被选中作为“普遍早期机制”。
E的L8合格正常当前差为+.238/+.273，而M8整窗差是−.283/−.295，再次说明不能混淆当前与整窗测量。
X前合格正常的当前S/CW中位数仅1.35/1.33，均值受重尾影响；L8只剩14条/53个look，当前差约+.010/−.628。
阶段之间查询集合/词条组成不同，不能直接相减作因果时间效应；query均由最后有X这个未来标签定义。

X对过度拒绝仍零匹配；对参与/承诺未执行仅5/1个look；合法拒绝仅11个look。
当前token分解没有创造任何新共同支持，也没有解决授权反事实缺失。
S/CW的尺度和定义不同，CW数值更大不是其超越S的信息增益证据；本轮不改变任何算法判断。

## 7. 下一步机制问题，与算法线的接口

优先做**正常—正常同token的对照**：在可比词条、通道、fold和因果位置下，正常任务内部上下文变化
是否也造成同样规模/层分布的路由差异？方案须先固定参照选择和支持度口径，不能看结果再放宽匹配。
同时把局部词序与更长上下文作为竞争解释，而不是从本轮直接跳到“理解意图”。

待区分的假设是：普通上下文变异、局部专家持续性、任务/体裁状态变化、授权相关状态。
本轮排除了主子集的“完全由7个未匹配位置贡献”解释，**还没有区分上述四者**。
同内容不同授权的受控复放仍需主管批准、独立数据namespace，并与自然生成的端到端效果分开。
现在不加载模型、不新增数据，不用G-conf补足机制研究的共同支持。

给副对话算法线的可用输入：**不要把token新颖性当成路由变化的充分解释；普通词也能承载路由差异。**
不能传递成“中层检测器一定最好”“权重一定有增益”“稀有专家就是任务意图专家”或新性能承诺。
