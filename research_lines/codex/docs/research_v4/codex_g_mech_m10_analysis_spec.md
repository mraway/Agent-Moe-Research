# 机制 M10：同 token 的正常—正常变异对照

2026-09-08。**G-dev development mechanism evidence，不是算法、确认性或因果实验。**
本方案先提交；代码、合成测试与独立审计再冻结，随后才读本轮数据。M7–M9及算法线文件不改。

## 1. 问题与可识别范围

M9在固定45个X窗口上发现当前token本身的S/CW差异，排除了“全部差异只在前7个token”的解释。
但正常上下文也能让同一token走不同路由。本轮问：在可匹配子集上，偏移—正常的当前token
**差异幅度**是否大于正常—正常的差异幅度？不把正常—正常有符号差的抵消当成稳定。
这里的“正常”只代表现有Atlas正常臂，**不包括系统性授权的题外创作对照**。
即使差异保留，也不区分体裁、语义、上下文长度、位置及授权；不证明普遍任务偏移机制。

## 2. 输入与 score-blind 三元组

仅用M7/M8/M9已冻结产物及M7记录SHA的M3 G-dev top-k/logit私有缓存。
不读原始trace、模型权重、G-conf（包括标签/封存清单）；不新生成、不前向、不重新拟合或校准。
产物独立放`artifacts/agent_v2/codex_g/mechanism_m10_normal_placebo_v1/`。

查询固定为M8的E_at、X_pre、X_at全部5562个阶段窗口，不按S/CW或检测结果选取。
主列为**X_at / filtered正常 / 不同场景**；原126条X正例、2142个X窗口均为支持度分母。
主列必须是M9原45个L1匹配query的子集；不把旧45个与新子集的均值直接相减。
E及X前只是条件于未来X标签的描述性列，不作早期检测证据。

对每个q，只按以下变量选择两个正常donor a,b：

- 三者M8结构完全相同：评价fold、harmony通道、episode index、已发生生成step、
  通道look序号//32、当前生成端点//64；当前token ID完全相同；8-token窗不跨step。
- q到各donor的8-token TU绝对差≤0.25，**a到b也≤0.25**。
  TU是冻结正常折拟合的词汇测量，不是路由分数。
- donor来自不同episode，且均不同于q的scenario。主列a,b还必须来自**不同scenario**，
  避免同场景clean/benign近重复把正常变异人为压低。
- 候选排序沿用M8的(TU绝对距离、端点绝对距离、端点、episode key)，每episode只保留首个。
  在这个固定排序上按(i,j)字典序枚举，取首个满足场景条件及相互TU条件的pair。
  只选两个，不根据分数选最相似或最相异donor；先完成并保存匹配图，再读取路由测量。
  失败分列：结构、TU、token、不同query场景后不足2个episode、无不同场景pair、相互TU不合格。

固定四格，不临时放松：①filtered/不同场景/0.25主格；②filtered/允许a,b同场景/0.25
（近重复敏感性）；③all正常/不同场景/0.25；④filtered/不同场景/0.10（所有三条边均收紧）。
四格的不同支持集分别报告；另在四格共同query子集上重报，空支持写不可估计。
主格选定三元组额外按三条边最大端点距离≤16作固定位置敏感性；不重新选donor。

## 3. 测量与统计单位

用M7各评价fold冻结q和实际入选专家重建M9定义的**当前token、未除8**的S与CW。
不再平均前7个token。保存24层贡献，校验8-token均值仍重放M8分数，并核对与M9重合位置。
CW只是既有“稀有选择×实际入选logit余量”，不是全概率分布的完整测量。

令u为当前token的S或CW总分，固定三元组报告：

`A=(|u(q)-u(a)|+|u(q)-u(b)|)/2`；`N=|u(a)-u(b)|`；`D=A-N`。

同时报告`u(q)-(u(a)+u(b))/2`及q严格高于两个donor的比例（数值tie容差1e-9）。
两个量都用**两两距离**，不混淆“query减donor均值”与“单donor之间”的不同方差尺度。
若三者可交换且选择不依赖路由，A与N的期望相同；**本观察性匹配不保证可交换**，
故D只是相对已选正常变异的差异幅度，不是p值、FAR、异常阈值或校正后的因果效应。
两个正常donor的范围不是正常分布置信区间；越过它的比例不叫recall。

同一公式应用于预定0–7、8–15、16–23层带的求和分数及全部24个单层分数。
绝对距离的层带和不等于总分距离；不作加性归因。rare mask在中层机会更多的M9限制继续成立。
不搜索最强层。保存每query的原分数、A/N/D、匹配距离、token、场景及全部失败原因。

先在episode内平均，再episode间等权；连续量输出均值、中位数、正差比例及家族bootstrap
2000次（seed=802608）95%区间，family×tier并列。区间条件于已选donor银行/图，
不覆盖donor复用、图选择、反复开发或多重比较的不确定性；单家族退化明确标注。
报告donor episode/scenario复用与有效权重、查询域/家族/通道/fold分布及三条边TU/位置平衡。
不对连续距离套McNemar；本轮没有二元检测器比较，不更新任何算法指标。
