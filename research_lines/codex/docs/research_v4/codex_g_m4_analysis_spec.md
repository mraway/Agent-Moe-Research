## 1. 固定参照与分解

复用 M3 原始冻结状态/阈值，不更改 S：每层正常入选边际频率 q，
`r_e = 1[q_e < .02]·(-log q_e)`。S=Σ r_e A_e，A 是实际缓存的 top4 指示器。
所有784个episode都进入描述，不只选择 S 的漏检或某个任务域。
V1/message、全24层、w8、H352 looks、三折fixture_rank_mod与轮转原样保留。

**身份读出分解**：对 M3 CU 的通道参照 JS 按同一个稀有 mask 精确分成 J_rare+J_common；
再以正常通道 token 数加权的全局 q_U 重算同一分解，避免把通道/全局参考差异误当稀有度效果。
同时保存 S、稀有入选次数、全坐标选择surprisal（P×96）。
逐look报告 S 的 top1/top3/(layer,expert) 集中度及三个固定8层带贡献；不据此选层或专家。
在正常参照路径的原 S/CU 标准化最大值端点与 E/X 阶段观察贡献结构，**不建立新报警器**。

**概率投影分解**：p 为全32专家float32 softmax后仅修正总和舍入的float64概率；
m=Σ_A p，U=A/4，V=pA/m，Q=p(1-A)/(1-m)。用 M2-B 同折/同通道正常 m0，逐token精确分解：

`Σ r p = m0·ΣrU + (m−m0)·ΣrU + m·Σr(V−U) + Σ_(not A) r p`。

四项依次是固定正常质量的身份项、质量变化项、入选内部非均匀项、未入选尾部项。
先算逐token乘积再平均窗口，不用均值乘积替代；分解是代数恒等式，**不是因果效应或条件互信息**。

## 2. 事件、正常控制与统计单位

窗口层复用 M2-A 固定的全部305个已匹配读数与同一完整结构足迹，不重选 donor。
同scenario(S)和同fixture/template(F)、filtered/all、E_level/X_level/E_did/X_did/EMX分别报告。
主要解释列为 S/filtered，F及all是敏感性；匹配覆盖率和正常-normal placebo保留。
原始分解项报告匹配均值/差分与家族bootstrap；不同量纲不直接比数值大小。
另用 M1 的同一正常窗口midrank机制（参考折正常、通道/位置/episode序号、原稀疏回退）
给每项各自建立描述性百分位。**不是conformal p，不是在线召回/FAR**。
所有结果episode等权；CI按攻击家族2000次percentile bootstrap，family×tier并报；
匹配/稀疏条件下的CI仅条件于当前donor，不声称平行趋势或因果识别。

全样本同时报告固定 E前16、E至E+16、中间段、X至X+16、X后17至64，正常/注入后silent40/
合法拒绝24分开；多轮注入前88个episode不混入静默攻击。保留截短/无端点/无事件及分母。

## 3. 两项局部概率/时间检查（预先固定，不按结果扩展）

**入选前与持续性**：每层的稀有专家在过去8个token均未入选、当前入选，定义一次进入事件。
要求[t−8,t+8]在同一harmony通道与Agent step内，且完整落在H_end之前；
记录lag −8/−4/−1/0/+1/+4/+8的p、p/当前第4个入选概率，以及未来8个token入选比例和连续驻留长度(封顶9)。
未来值仅用于离线机理描述，绝不作为在线特征。接近top-k阈值本身是事件定义的必然结果，
必须与**相同(layer,expert,channel)**的正常进入事件比较，而不能把普遍跨阈行为当攻击前兆。
正常bank来自同一折轮转的reference正常臂、用query折的同一个rare mask；至少5次事件、3个不同正常episode。
先对每个donor episode求均值、再对donor求均值；query再按episode求均值，避免token/事件伪重复。
不做近邻回退；缺少匹配时只报覆盖率。区分E、X、E/X之外阶段；另列完整足迹严格早于X的E/中间事件。

**固定支持集的权重变化**：相邻token在同一通道/step，某层实际top4集合完全相同。
此时该层S严格不变，检查稀有专家入选概率投影/尾部投影的有向变化与绝对变化、Δm。
与相同(layer,完整top4集合,channel)的正常稳定对比较，同样至少5对/3个donor episode，不回退。
支持集匹配是局部描述，不代表完整24层支持保持不变；如覆盖稀疏，不能泛化到整批。

## 4. 判读与停止条件

M4不宣布某个新算法优胜。只有概率变化在正常结构控制后仍有一致方向、覆盖多个家族，
且不只是正常转场/静默/合法拒绝时，才把它列为下一轮算法假设；不按显著性挑域/层/时间窗。
若主要是S已解释的身份变化，或精确支持匹配不足，就报告这个边界，不用复杂模型掩盖。
仅在形成具体机制假设后，另写包含原样S作为特例的低参数算法方案，并回到入门包§5完整评价。
本轮既有 S/CU p流只用于定位原正常最大值和复现，不用于选择新工作点。
预注册/阈值冻结并获主管批准之前，G-conf任何轨迹/路由/标注/封存清单均不读取。
