## 1. 问题与不变项

主问题：在**同一(layer,expert)**、当前是否入选及过去8-token的入选序列相同的条件下，
该专家当前连续概率是否仍偏离正常？控制只是单专家历史，**不是整个top4/全层身份历史**。
竞争解释：入选次数、连续性、通道/位置变化，而非连续权重本身提供的增量。

复用M3的S正常拟合q与固定 `q<.02` mask；全24层、V1/message、w8、H352 looks、同三折轮转。
评价折k，q仍来自k+1；条件正常bank来自k+2的filtered正常episode，不纳入攻击/合法拒绝。
使用原共享look端点，另对机制读数要求[t−7,t]在同一Agent step和通道内；不更改共享look栅格或H。
不要求未来仍有token/进入事件，不查看t以后的概率。无合格look/无匹配按缺失报告，不填零。

## 2. 固定的嵌套正常控制

每个合格look，对每个稀有(layer,expert)保存8-bit实际入选历史h，最低bit为当前token。
选择状态为当前bit，c是8-bit入选次数；s为以当前token结尾的连续入选长度（封顶8），d为7次相邻切换数。

| 控制 | 正常bin的键 | 作用 |
|---|---|---|
| B | layer, expert, channel, 当前入选bit | 身份/当前状态 |
| C | B + c | 进一步固定该专家对原S窗口的贡献 |
| H（主解释列） | layer, expert, channel, 完整8-bit h | 再固定单专家的因果顺序 |
| HP（敏感性） | H + episode_index + 原通道look ordinal//32 | 检查位置/轮次残余混杂 |

所有bin至少5个coordinate-look观测且3个不同正常donor episode；先对每个donor episode取均值，再等权合并。
**无回退、无按攻击结果选择粒度、无平滑拟合**。四列都报告原生覆盖。
比较B/C/H时，另只用H合格的同一批query coordinate-look；比较H/HP时只用HP合格的同一批query。
不能用更严格匹配造成的样本改变冒充“信号被解释掉”。全部层、专家、任务域保留。

## 3. 概率与二值历史读数

p是完整32专家softmax，A为实际缓存top4；m=Σ_A p。
逐coordinate-look输出以下7项，不选择分数或报警阈值：

1. 当前p_e；
2. 当前所属集合内的条件概率：入选时p_e/m，未入选时p_e/(1−m)；两组分开，绝不混合量纲解释；
3. log(p_e / 当前实际top4的最小概率)，以消除单纯阈值水平变化的一部分影响；
4. 本层m（用于诊断概率与集合质量的关系，不作为独立专家观测扩大样本量）；
5–7. c、s、d（占用/连续性竞争解释与匹配恒等式测试）。

C下c残差必须为零；H/HP下c/s/d残差必须为零。原p、条件概率、阈值余量分别报告，
不把m增加等同于内部配比增加。概率在给定单专家历史后有残差，不等同于超过完整身份检测器。

## 4. 两阶段执行、样本与推断

正常阶段只加载从配置/目录预先筛出的正常轨迹，臂别还原auto；验证M4记录的输入/缓存哈希。
G-dev已公开标签/元数据用于normal质量和fold join，**不声称标签盲态**。输出正常bank、
三折正常留出读数和覆盖，冻结bank文件SHA256。第二阶段恢复bank并机械禁止新增donor或重新拟合，
完整五臂784个episode复现；正常episode逐个摘要应与正常阶段完全一致。

当前入选/未入选两组，各自按episode内coordinate-look均值、再episode等权报告raw/control/residual。
这是单专家条件的局部均值，不是一个在线全层报警流。
固定阶段：全H、E前16、E至E+16、E后17至X前、中间若无X则缺失、X至X+16、X后17至64；
另列E窗口严格早于X的部分及E无X。阶段划分只在特征和正常匹配完成后加入。
正常all408/filtered293、benign_lexical24、legitimate_refusal24、载注入264、静默40、注入前88分别保留。
每列同时给总eligible事件/episode、matched事件/episode、家族数、分组覆盖；不将coordinate-look作为独立样本。
攻击CI用家族和family×tier bootstrap各2000次（seed20260908），条件于当前正常bank和覆盖。
family/域组/注入渠道/措辞/折/轨迹类的描述全部保留，不按显著性选组。

## 5. 判读和下一步

若概率差只存在于B/C而在**同query样本**的H中消失，优先解释为单专家因果身份历史已解释。
若H仍存在而HP消失，或HP覆盖很差，则保留位置混杂/检验力不足，不主张稳健条件增量。
若条件概率与阈值余量在控制后仍有一致方向且跨多个家族，并非正常/静默/合法拒绝的普遍残差，
才形成下一轮包含原样S、因果历史对照、连续概率增量的低参数算法候选；本轮不直接选算法。
没有差异不等于无信息；覆盖不足、其他专家未受控、反复开发和参照不确定性必须写进报告。
不产生新FAR/召回/McNemar结论；正式算法实验另冻结并接入共享§5口径后执行，G-conf继续封存。
