# M10：同 token 正常变异对照——残差保留，但共同支持进一步收缩

2026-09-08。**gpt-oss-20b / Agent v3 / G-dev development mechanism evidence。**
本轮没有新检测器、阈值、recall或FAR；没有模型前向或新生成；G-conf及其标签/封存清单未读。

## 1. 结论先行

在能找到**两个不同场景正常对照**的X阶段子集上，同token的偏移—正常稀有专家特征差异，
仍大于所选正常—正常对照的差异。当前token现象并未被这一对照消除。
但主列只剩**5/126条episode、7/2142个X窗口（0.327%）**，且一个数学case贡献了约63%的S均值。
因此，这是几个严格匹配案例上的存在性观察，不是全批、全任务或授权意图的机制结论。

另一个更有覆盖面的结果是：**E阶段的S/CW差异幅度没有明确超出正常变异**。
同场景正常近重复的选择会改变这个读数，说明正常对照的独立性是实际影响机制判断的设计因素。

必须限定“变异”的对象：这里比较的是**稀有专家投影S及其既有权重调制CW**，不是完整路由向量。
S/CW为0不代表路由相同，只代表没有这些稀有坐标的贡献。下一步应检验完整选择/概率分布，
不能据正常S/CW接近零宣称“正常上下文的路由不变”。

## 2. 设计与可复核口径

方案：[M10冻结说明](codex_g_mech_m10_analysis_spec.md)，方案提交`78109f3`；
实现及审计提交`3ade36e6893c51fc6e9acb874834ab754f762e86`，均在本轮数据读取前冻结。
起点：[M9报告](codex_g_mech_m9_report.md)。M7完整episode观察范围与M8阶段窗口保持不变。

对M8全部5562个E/X前/X窗口先作不看路由分数的匹配。对每个query q找两个正常donor a,b：
当前token ID、fold、通道、episode index、生成step及两种因果位置桶均相同；
q-a、q-b、a-b三条边的8-token TU差均≤0.25；a,b来自不同episode、不同scenario，均非q的scenario。
按事先冻结的TU/端点距离/episode key排序选pair，先保存图，再重建路由测量。
旧产物的完整性哈希校验不等于把其路由分数交给匹配器；匹配API不接触路由/结果字段。

S/CW沿用M7各留出fold的正常拟合q、rare mask及实际入选专家，不重新拟合。
本轮是**当前token原始分数**，不是8-token平均、标准化z或报警概率。记当前读出为u：

`A = (|u(q)-u(a)| + |u(q)-u(b)|)/2`

`N = |u(a)-u(b)|`，`D = A-N`。

A、N都是两两距离，避免将“到两个正常均值的距离”与“单个正常之间的距离”混用。
另报有符号差`u(q)-(u(a)+u(b))/2`及q高于两个donor的描述性比例。
若三点可交换，D的期望为0；**本观察性匹配不保证可交换**，不将D称作因果残差或显著性分数。

每episode内平均，再episode间平权。下文CI均为条件于匹配图/银行的家族bootstrap 2000次、
seed 802608；family×tier列在产物中并列。未计donor银行不确定性、复用、反复开发或多重比较。
连续距离不使用McNemar；本轮没有检测器二元结果比较。

## 5. E与X前：正常变异能解释到什么程度

下表均为filtered/不同场景主匹配规则；阶段查询来自**最终有X标签的episode**。

| 阶段 | episode/look；家族数 | S：A / N / D [95%CI] | CW：A / N / D [95%CI] |
|---|---|---|---|
| E_at | 78/195；16 | 2.921 / 2.528 / **0.393 [-0.309,1.108]** | 3.117 / 2.645 / **0.472 [-0.240,1.213]** |
| X_pre | 67/144；15 | 13.002 / 3.543 / **9.459 [1.081,27.229]** | 16.076 / 3.630 / **12.446 [1.263,36.793]** |

E主列覆盖195/1453个阶段look（13.42%）；有符号S/CW差0.156/0.209，区间均跨0。
位置≤16后70条/166个look，D仍跨0：S0.408[-0.307,1.104]、CW0.489[-0.221,1.197]。
这不是等效性检验证明“E无信号”，而是现有测量尚未显示明确超出正常变异。

X前覆盖144/1967个look（7.32%）；D的episode中位数仅S0.812、CW0.633，明显小于均值。
S为40/67条平均D正，CW为39/67；不应把重尾平均效应称作稳定普遍提前信号。
位置≤16后40条/60个look，S7.521[0.638,26.378]、CW9.869[0.873,34.839]，仍很宽。
有符号差、全部分层与四格共同子集均落盘；这些读数不构成在线早期recall，
也不改变E/X onset。阶段样本不同，不将三行连成同一群体的连续动力学曲线。

它说明不能依赖同场景clean/benign近重复所产生的小N来宣称强早期机制。

## 7. 机制判断与下一步

截至M10，可以保留的观察链是：

1. M9排除了有限匹配窗口的差异**全部**来自未匹配前7个token；当前token也有差异。
2. M10进一步显示：少数X匹配三元组上，该差异幅度大于现有正常对照的同一稀有投影变异。
3. E阶段较广支持下，S/CW尚未显示明确超出正常变异；近重复正常对照会改变读数。

仍未排除：输出体裁/语义模式、局部专家持续性、更长上下文、输入或生成位置、
正常银行覆盖过窄及rare mask的测量机会偏差。不存在“同内容、不同授权”的系统性对照，
因此不能在论文中写成“路由已经识别未经授权的意图”或“专门的任务偏移专家”。

**建议下轮仍做机制，不调检测器**：在冻结对照上比较完整实际入选向量与全32路概率分布，
分清“正常稀有得分为零”和“正常路由不变”；再检查更严格局部token历史匹配的支持度。
前者直接回应完整权重信息的机制问题，而不是先假定权重一定胜出。
若现有数据无法区分体裁/内容与授权，须明确停在识别边界；另行申请独立命名空间的
同内容/不同授权受控复放，不能自行补数据、重掷共享工厂或打开G-conf。
