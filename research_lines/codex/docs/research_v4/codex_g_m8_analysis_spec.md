## 1. 问题与反证标准

M7的S/CW在拒绝类轨迹上少报，可能反映执行选择性，也可能仅由词汇、通道、位置等因素解释。
本轮问：控制已有弱文本读出TU、因果位置与部分/完整token身份后，X附近路由分数是否仍有差异？
正残差不自动证明因果机制或超越强文本；缺少共同支持不等于效应为零。

不按M7“谁检出”选择主查询，不只分析低误报S-only20条：主查询覆盖全部126条X正例。
拒绝/无执行控制是事后结果类，不能声称是随机分配的授权反事实。

## 3. 先固定匹配，再读取路由残差

共同结构键：同评价fold、harmony通道、episode_index、generation step序号、
`channel_look_ordinal//32`、`global_end//64`。它们均为当前可见前缀坐标。
不匹配最终episode长度，不按未来停机位置/持续入选/最终输出内容的后缀选donor。

三档嵌套匹配，全部报告，不选“最佳档”：
- **L0**：共同结构键 + `abs(TU_query-TU_donor)<=.25` nats。
- **L1（主描述档）**：L0 + 当前token id完全相同。
- **L8**：L1 + 当前因果8-token序列完全相同，用于检验最严格词汇控制下是否有共同支持。

额外固定敏感性：L1的TU caliper收紧到.10；不事后放宽任何窗口/位置格。
同一donor episode只选一个窗口：按TU距离、绝对端点距离、端点排序取最近；
再按上述距离及episode key确定性地取最多3个不同donor episode。平权平均donor，
禁止以S/CW/raw z差或是否报警选择、排序或剔除匹配。

至少1个donor的结果与至少3个donor的稳健子集分别报告。L0/L1的变化另在相同L1合格查询上比较；
L1/.25与L1/.10另在相同严格查询上比较，不能将覆盖改变误当成残差消失。
无匹配分为结构无共同支持、TU超caliper、当前token不符、整窗token不符。

## 4. 估计量与不确定性

每查询窗口的差为query减donor平均，保存S/CW/TU原分数和三格当前窗口z共6列。
同一query episode内先平均，再对episode平权；不把重叠look当独立样本。
均值/中位数/正差比例、按query attack_family聚类bootstrap2000次的描述性区间，
family×wording_tier稳健列；报告家族数、每家族episode数及donor复用。
区间条件于既定匹配图和donor银行，未计donor复用与选样的不确定性，不作确认性显著性宣告。
本轮不比较新的二元检测器，故不把连续残差强行交给McNemar；M7二元结果保持原样。

主矩阵：3阶段×6对照×4匹配档，S与CW均完整报告。
每格报告126个候选episode、实际有查询的episode、查询look数、匹配episode/look比例、
至少3donor覆盖、独立donor episode/scenario数、最大复用、家族与通道/位置分布。
同时报告TU残差、TU绝对距离和位置差，防止“已经匹配”掩盖剩余混淆。
全部候选与匹配成功子集的无匹配原均值分开给出；不以少数可匹配token推论全体任务偏移。
