# A01 v1：正常路由近邻的表示实验

2026-09-08。G-dev 开发实验，不是 G-conf 预注册，也不构成生产 FAR 保证。
上位设计：[算法实验总计划](codex_g_algorithm_experiment_plan.md) §6–8。

## 1. 问题与冻结候选

完整路由的局部正常参照，能否在相同实测正常误报下优于稀有专家 S？
只运行 `U_mean / W_mean / U_ordered / W_ordered` 四格；不扫参数或挑层。
U 为实际 top-4 入选 mask 除以 4；W 为实际入选的四个 router logits 上的 softmax，
其余专家为零。固定 24 层、32 专家，使用缓存 IDs，不重新按 logits 排名。

每层平方 Hellinger 距离为 `h²(a,b)=0.5 Σ_e(√a_e−√b_e)²`。
mean 格先平均窗口内各坐标再比较，最后 24 层平权；ordered 格逐对应位置比较，
再在 8 个位置及 24 层平权。ordered 不等于纯顺序消融：它同时保留均值丢失的
逐 token 变异。禁止将比较结果直接命名为跨层依赖、思考类别或意图识别。

M9 完整报告已在本轮评分前读入：同一常用 token 上仍有局部路由差异，
但支持仅 28/126 个 episode，不能排除正常上下文变化等解释；R_t 是处理已采样 y_t
的路由，不是采样 y_t 之前的预测状态。本轮不因此挑中层、不增加新候选。

## 2. 因果网格和库

沿用 M7 **完整 episode** 的 V1/message、w8、stride1 端点/通道内 ordinal，
不再施加历史 H352 截断。共享校准采用 `force_h=2**31-1`，并断言实际长度远小于该值。
这是一项明确的开发协议差异；未来两线确认的观察协议仍需统一。
所有窗口同一通道、同一生成 step；新发现跨 step 端点时停止，不静默删端点。

沿用冻结 `fixture_rank_mod` 三折：评价 k，拟合 (k+1)%3，校准 (k+2)%3。
仅拟合折 `filter_pass is True` 的 clean/benign_control/benign_lexical 建库。
库仅按 `(channel, episode_index)` 条件化，使用全部合格窗口。每个 scenario 先取
最近窗口，再取最近 3 个不同 scenario 的距离均值。保存三名 donor 的 scenario、
episode key、端点和距离。按距离、scenario 字典序确定场景平局；场景内按
episode key 字典序、端点升序确定平局。无 token/题材匹配、无 PCA/ANN/训练编码器。

拟合折流用于标准化时，必须排除查询的**整个 scenario**，包括其他臂/回合/重叠窗。
cal/eval 场景不得出现在拟合库。每个所需条件在排除后必须仍有 ≥3 donor scenario；
不满足则报告覆盖失败并停止，不返回零、不借其他条件、不减少 k、不丢评价分母。
长场景的候选数量优势如实记录；不在本轮抽样压缩库。

## 3. 数值实现与合成验证

对平方根表示使用分块精确内积，距离按两向量各自范数计算，避免浮点归一化误差
被 `1−dot` 掩盖。逐 token kernel 可沿窗口对角线平均，与展平 8-token 表示的
距离在数学上等价，不是额外平滑。float32 特征/内积，float64 小规模直接公式审计；
直接距离绝对误差要求 ≤2e−6。只允许将容差内的负平方距离裁剪到零；非有限值报错。
固定分块设置，恢复时不因负载改变数值实现；近邻平局按上节规则确定。

测试涵盖：U/W 单纯形与实际 top-k、直接 Hellinger 等价、均值/位置区别、
未来追加不改变旧分数、通道/step 边界、场景去重与整场景排除、空/不足支持报错、
NaN/inf 拒绝、分块一致性和保存恢复。评分后另作独立逐坐标距离抽查与共享首报重放。
