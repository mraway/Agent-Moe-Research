### B1（§9.2 F1 / §17.2 / §16.4 R1）**F1 的逐折 ±0.03 带从来没有按抽样噪声标定过；在完美可交换的零假设下它就有约 64% 的失败率，而"Z1 的注册理由"被绑在它身上**

**正文怎么说的。** §9.2 F1：主格是单统计量，"保形构造把实测 FAR **钉在** `alpha_eff` 上，F1 是一条**恒等式检验**"；
判据是**逐折** `|far.filtered_k − alpha_eff_k| ≤ 0.03`，**三折都要成立**。
§17.2 预判 **PASS（首次）**，并写死一条推断：
"**若在 G-conf-2 上仍失败，Z1 的注册理由就没有了**（报告必须逐字这么写）"。§16.4 R1 重复同一句。

**问题。** "钉在 `alpha_eff` 上"只是**期望**成立，不是恒等式。留出折的 FAR 是一个两样本秩统计量：
留出折的 `n_eval` 条 episode 各自与参照折的 `n_cal` 条比较，方差既有留出侧的二项噪声，
**又有阈值本身（参照折第 r 大）的抽样噪声**。我按代码的判据
（`p(k) = (1 + #{g : Z^g ≥ R(k)})/(n_cal+1) ≤ α` ⇔ `#{ref ≥ target} ≤ floor(α(n_cal+1)) − 1`）
在**完美可交换**下直接模拟（把 N 条可交换分数按真实折大小切三折，2 万次重复）：

| 折大小（过滤后） | `alpha_eff` 三折 | 逐折 FAR 的 **SD** | P(单折 \|dev\| ≤ 0.03) | **P(三折全带内)** | P(汇总 \|dev\| ≤ 0.03) |
|---|---|---|---|---|---|
| **G-dev 95 / 94 / 104** | .09524 / .09375 / .09474 | **0.0413 / 0.0422 / 0.0410** | .475 / .557 / .525 | **0.188** | 0.991 |
| **G-conf-2 投影 170 / 185 / 168** | .09467 / .09942 / .09677 | **0.0316 / 0.0314 / 0.0314** | .699 / .662 / .657 | **0.358** | 1.000 |

三个后果：

1. **G-dev 上"三折首次全部带内"（−0.0110 / +0.0020 / −0.0274）是一个先验概率 ≈ 0.19 的事件。**
   把它当作 `Z1` 的机制证据（§0 第 1 条、§2.5、§9.2 F1、§17.2）是过度解读。
   `S` 的折 0 偏差 +0.0942 ≈ **2.3 SD**，那**确实**是异常；但"`Z1` 三折全带内"与"运气"不可区分。
2. **§17.2 的"预判 PASS（首次）"是一个先验概率 ≈ 0.36 的预判**（G-conf-2 的折还更不均，见 §16.2），
   而正文把它列为 v3.3 相对 v3.2 唯一预判失败的门只剩 N1 的依据。
3. **最严重的一条**：注册的推断"F1 逐折失败 ⇒ Z1 的注册理由没有了"会在**一切都正确**的情况下
   以 ≈ **64%** 的概率触发。这不是一条可证伪的判据，是一条几乎必然触发的自毁开关。

**同时，F1 的另一半（汇总列）是空转的**：在同样的零假设下汇总偏差的 SD 只有 **0.0103 / 0.0069**，
±0.03 是 **2.9 / 4.3 SD**，通过率 0.99 / 1.00。**所以 F1 的两条臂一个几乎必过、一个多半必败，没有一条是标定过的。**

**这正是 v3.2 审阅 S7 的未闭合部分。** S7 指出汇总形式的 F1 在完美可交换下也有 ~90% 通过率（我复算是 99%），
组长裁定"改逐折"；**但逐折形式的噪声从未被算过**，改动把一条过松的门换成了一条过紧的门。

**修法（择一，A″ 之前必须选定）。**
(a) **把带宽按噪声定**：用上表的 SD 定 `±2 SD`（G-conf-2 ≈ ±0.063），或者直接把 F1 写成
**一个精确的两样本检验**（超几何 / 置换 p 值，三折用 Fisher 合并），门在 p 上而不是在绝对偏差上；
(b) 保留 ±0.03，但**把逐折降为记录项、汇总保留为门**，并删掉"F1 逐折失败 ⇒ Z1 的注册理由没有了"这条推断；
(c) 保留现状，但在 §9.2 F1 与 §17.2 **逐字写进上表**（零假设下三折通过率 0.36），
并把注册推断改成"F1 逐折失败**不**推翻 Z1，因为该判据在零假设下就有 64% 的失败率"。
**无论选哪条，"恒等式检验"这个措辞必须删掉**——它正是导致带宽没被标定的那个说法。

### B2（§10.3 `VAL1` 判据 (a)）**判据 (a) 有两种读法，两种读法在零假设下的通过率相差 50 倍；按正文字面的读法它几乎注定失败**

**正文怎么说的。** §10.3 判据 (a)：
"每一层的留出 `far.filtered` 落在 `[alpha_eff_stratum − 0.05, alpha_eff_stratum + 0.05]` 内
（`alpha_eff_stratum` = **该层该折**的可达 α，逐层落盘）"。
理由："±0.05 是逐层 `n_cal` 变小之后蒙特卡洛噪声的量级（`n_cal ≈ 30` 时单条 episode 值 0.033，±0.05 ≈ 1.5 条）"。

**问题 1：读法不唯一。** "该层该折的可达 α"把 `alpha_eff` 定成**逐层逐折**的，
但被比较的量写作"每一层的留出 `far.filtered`"（**逐层**）。于是有两种可执行读法：
**(i) 9 个 (层 × 折) 判定全部成立**；**(ii) 3 个层各自把三折合并后判定**。
在 G-conf-2 的投影层大小（过滤后 34/33/30 · 78/87/78 · 58/65/61）上，按同一套零假设模拟：

| 读法 | 逐层的单项 SD | 零假设下的通过率 |
|---|---|---|
| **(i) 逐层逐折，9 项全过** | 0.072 / 0.068 / 0.070（`n_kb=0`）、0.044 – 0.045（`n_kb=1`）、0.050 – 0.053（`n_kb=2`） | **0.019** |
| **(ii) 逐层合并三折，3 项全过** | 0.0223 / 0.0115 / 0.0141 | **0.963** |

**一条注册判据不能在两种字面读法之间差 50 倍的通过率。**

**问题 2：±0.05 的理由算错了。** "`n_cal ≈ 30` 时单条 episode 值 0.033"算的是**分辨率**（1/30），不是**抽样标准差**。
最小层的逐折 SD 实测是 **0.072**（≈ 2.2 条 episode），±0.05 只有 **0.70 SD**。
按读法 (i)，`VAL1` 的判据 (a) 在**分层完全正确**的情况下也有 **98%** 的概率被判失败。

**问题 3：§11.3 第 3 条说"该判据在 G-dev 上未被逐层核算过、是先验写死的"，但正文自己已经给出了足以证伪它的数**。
§10.3 的收益行写着分层后 G-dev 的条件 FAR 是 `n_kb=0` **16/81 = .1975** · `=1` **17/204 = .0833** · `=2` **11/123 = .0894**。
G-dev 分层后逐层可达秩是 **1–5**（§2.6 / §4.4），即 `alpha_eff_stratum ≤ 0.10`。
**0.1975 与任何 ≤ 0.10 的 `alpha_eff` 相差 ≥ 0.097，是 ±0.05 的近两倍。** 也就是说：
判据 (a) 在 G-dev 上**已经失败**（至少在 `n_kb = 0` 层上，而且不是边缘失败），
正文却把它写成"完全是先验"。这不是纪律问题（用开发集读数改判据才是），
而是**正文欠了一句"按 G-dev 的读数，(a) 预判失败"**——否则 §17.3 的"方向预期成立"是没有依据的。

**修法。** (1) 把 (a) 的读法在正文里唯一化（建议 (ii)：逐层合并三折，`alpha_eff_stratum` 用该层三折的 eval 加权值）；
(2) 带宽按上表的 SD 重定（读法 (ii) 下 ±0.05 ≈ 2.2 / 4.3 / 3.5 SD，可保留；读法 (i) 下必须放宽到 ±0.15 量级）；
(3) §17.3 的 `VAL1` 预判按 G-dev 的 .1975 / .0833 / .0894 重写为"**(a) 预判失败，(b) 预判边缘通过**"。

### S3（§2.3）**"折 1 的 `rule_H` = 89 < 90 说明 `min_survivors = 90` 规则本来就不成立"是量纲错误，且与产物记录相反**

`trm3_g.h_horizon` 里 `H` 是**look 数**（第 90 长路径的端点数），`min_survivors` 是**路径条数**。
两者不可比。开发产物 `v3_3_dev/stage1_hinf_nostrat_d1/threshold_manifest.json` 逐折记着：

```
fold 0: rule_H 113  rule_survivors_at_H 90  H_effective 552  calibration_paths 104
fold 1: rule_H  89  rule_survivors_at_H 90  H_effective 628  calibration_paths  95
fold 2: rule_H 107  rule_survivors_at_H 90  H_effective 668  calibration_paths  94
```

**`rule_survivors_at_H = 90` ⇒ `min_survivors = 90` 的规则在折 1 上是成立的**，它给出的 H 恰好是 89 look。
真正不成立的是 **N3 的阈值 `H ≥ 128`**（89 < 128，另两折 113 / 107 也 < 128）。
结论（N3 在本设计下不可达、降为 `n/a`）没错，**给出的理由是错的**，而这条理由是 §0 第 3 条与 §9.1 N3 的依据。

**修法。** §2.3 改为"三折 `rule_H` = 113 / 89 / 107，`rule_survivors_at_H` 三折均为 90（规则本身成立），
但**三折都够不到 N3 的 128 look 门槛**——这正是 N3 在轮转折下早已不可达的证据"。

### S4（§1.3 / §2.4 / §4.3 / §17.4 / §18 D-7）**R1 唯一被写死的方向性预测在 G-conf-2 上不可评价；另一条"预测"是定义上的恒真**

§1.3：「**唯一可以事前写死的方向性预测**是：**在删失更重的批上，R1 的收益更大**（§17.1）。」

### S5（§9.2 F4 / §17.2 / §16.4 R2）**F4 是唯一的硬门，被提前声明"有实质失败风险"，但它在 G-conf-2 上的分母从未投影，失败概率也从未量化**

- **分母缺失**：§4 的三张 N 表里**没有静默攻击 episode 的 G-conf-2 投影**。已知的两个批差 2 倍（G-dev 40、G-conf 21），
  而 F4 的余量（G-dev 0.00833）在 21 的分母上等于 **1/6 条 episode**，在 40 的分母上等于 1/3 条。
- **失败概率未量化**：按 §9.2 自己的结构性论证（"静默 episode 在 `Z1` 通道上与正常 episode 无异 ⇒ 静默报警率 ≈ FAR"），
  取 `p_silent = p_clean = 0.095`、`clean.all` 分母 336，模拟 `P(silent_hat > clean_hat + 0.05)`：

| `n_silent` | 静默率 = FAR（结构性论证） | 静默率 = 1.5 × FAR（G-dev 实测 .125 vs .0833） |
|---:|---:|---:|
| 21 | **0.223** | **0.467** |
| 30 | 0.177 | 0.459 |
| 40 | 0.155 | 0.464 |

  即：**即使正文的结构性论证完全成立，F4 也有 16–22% 的概率失败；按 G-dev 实测的抬升幅度，接近抛硬币。**
- **结构性论证与数据不符**：若静默率真的 ≈ FAR，余量应当 ≈ 0.05；实测余量是 **0.008**，
  因为 G-dev 的静默率 0.125 是 `clean.all` 0.0833 的 **1.5 倍**。
  §9.2 仍逐字保留"静默报警率 ≈ FAR ≈ 阈值 − 0.05，**F4 结构性通过**"，与它下一句"失败概率已经不可忽略"互相打架。

**修法。** §4 补一行 G-conf-2 静默分母投影（`g_conf2.json` 上可算，不需要标注）；
§9.2 F4 / §17.2 把"有实质失败风险"换成上表的数；把"结构性通过"改成
"**在静默率 ≈ FAR 的假设下 F4 的失败率是 16–22%；实测的静默率是 FAR 的 1.5 倍，失败率接近 0.46**"。
