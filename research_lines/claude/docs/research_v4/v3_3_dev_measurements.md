### 2.1 从这张表读出的五条

1. **R1（H = ∞）在每一个统计量、每一个去抖、每一个分层下都是净收益**：

2. **R2（Z1）只有在 R1 之上才值得**：`Z1 · H=352` 与 `S · H=352` 命中相同（103/125），
   只把 FAR 压低（0.11945 → 0.08191，−31.4%），但 F4 因此**失败**；

3. **R3（去抖）在 `H = 352` 上救 F4、在 `H = ∞` 上杀 F4**。

   **"检测器更干净"与"F4 更容易失败"在这一格上是同一件事**（放大镜 §6 开放问题 1 的实证版）。
4. **R3 还结构性地破坏 F1**。去抖之后实测 FAR 不再被保形构造钉在 `alpha_eff` 上，只剩单侧上界：

`1 − U_(rank) ~ Beta(rank, n_cal + 1 − rank)`；给定它，留出 episode 条件 iid Bernoulli ⇒ 计数是 Pólya 瓮的 beta-binomial。
方差是二项的 `(n_cal + 1 + n_eval) / (n_cal + 2)` 倍：**G-dev 1.8868 / 1.9588 / 2.0729、G-conf 2.0287 / 1.9341 / 1.9884**。
