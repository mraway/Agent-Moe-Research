## 0. 为什么可以事后重算（本文件的方法论前提）

冻结的报警规则就是 **`p(k) <= alpha`**，其中 `p` 是 **running-max 保形 p 值**
（`trm3.DecisionStream.alarm_ends`：`[end for end, p in zip(ends, p_fused) if p <= alpha]`）。
因此：

1. **任何 α 都可以从已存的 `p` 事后重判**，不需要重新打分。α 只在"可达格点"上生效：
   `alpha_eff = floor(alpha * (n_cal + 1)) / (n_cal + 1)`。
2. **`p` 在本批上逐条严格单调不增**：2352 个 (episode × 格) 里 **0 个**出现 `p` 上升
   （`fusion_diag.json.p_monotone`）。这一条有两个直接后果，见 §5 与 §6。
3. 每个格的校准池都是**目标批自己的、质量过滤后的正常臂**（三折轮转），
   **攻击标签从不进入拟合或校准**。因此下面每一条组合规则都**保持一类（normals-only）性质**——
   组合只是把两个只用正常样本标定的 p 值放进一个布尔式子里。
4. **anytime FAR 保证**：单格是 `P(∃k: p_T(k) <= α) <= α`。
   - **OR**（并集）按 union bound 得 `<= α_1 + α_2`：**把总预算切开就保住 0.10**。
   - **AND**（合取）`<= min(α_1, α_2)`：两臂都用 0.10 时保证仍是 0.10（实测远低于它）。
   - **去抖 / 预算切分**：报警集是单格 α 报警集的**子集**，保证被继承。
   下表中带 `*` 的行**不满足 0.10 的 anytime 保证**（总预算超了），只作对照。

**逐折可达格点**（`threshold_manifest.folds[*].cells.S.n_cal` = 104 / 95 / 94）：

| α | 折 0（n_cal 104） | 折 1（n_cal 95） | 折 2（n_cal 94） | 可达？ |
|---|---|---|---|---|
| 0.10 | 10/105 = 0.09524 | 9/96 = 0.09375 | 9/95 = 0.09474 | 是（注册工作点） |
| 0.07 | 7/105 = 0.06667 | 6/96 = 0.06250 | 6/95 = 0.06316 | 是 |
| 0.05 | 5/105 = 0.04762 | 4/96 = 0.04167 | 4/95 = 0.04211 | 是 |
| 0.03 | 3/105 = 0.02857 | 2/96 = 0.02083 | 2/95 = 0.02105 | 是 |
| 0.02 | 2/105 = 0.01905 | 1/96 = 0.01042 | 1/95 = 0.01053 | 是（折 1/2 只剩 1 个格点） |
| **0.01** | 1/105 = 0.00952 | **0/96 = 0** | **0/95 = 0** | **否**：折 1、折 2 上永不报警 |

⇒ **0.05/0.05 与 0.07/0.03 的切分在现在的 `n_cal` 下都可达；0.01 不可达**，
任何"一臂给 0.01"的方案在三折里有两折是死臂。

## 3. (b) AND / 一致性融合：这是本轮最干净的"降 FAR"手段

**AND-look（同一个 look 上两格都 `p <= α`）与 AND-episode（两格各自报过警，取较晚的那个 onset）
在本批上逐位相同**——因为 `p` 单调（§0 第 2 点），两格一旦报警就不会撤销，
所以"第一个共同 look" = "两个首报警的较大者"。**这两种一致性口径在 G-dev 上是同一个规则。**

`AND-look(S@0.10, M@0.10)`：

- 命中 **100/125 = 0.800**（比 S@0.10 少 3 条，家族聚类 Δ = **−0.024**，CI **[−0.056, 0.000]**，McNemar p = 0.25）；
- FAR filtered **0.03413（10/293）**，比 0.11945 **降 71%**；FAR all 0.03186（13/408）；
- 逐折 filtered **0.0632 / 0.0213 / 0.0192**（异质性从 2.5× 降到 3.3×，但绝对量级全部在 2–6%）；
- 最差长度档 long **0.08108 → F3 PASS**（唯一一个远过线且不牺牲 8% 以上命中的规则）；
- 静默 **1/40**；场景级 FAR 0.05096；
- **anytime 保证：`P(AND) <= P(S 报警) <= 0.10`，保证被保住**（实测远低于它）。

**代价**：`F1` 变得没意义——实测 0.0341 对 `alpha_eff_w` 0.0946，偏差 **0.0605 > 0.03，F1 FAIL**。
这不是"检测器坏了"，而是 **F1 在合取规则下从"恒等式"退化成"上界"**：
注册的 F1 检验的是折间可交换性（`freeze_review_v3_2_statistics.md` S7 的原话），
合取规则的实测率被结构性地压到 α 以下，**F1 必须重新定义或明写为不适用**。

**如果把 α 放宽到 0.15/0.15** 换命中：104/125 @ FAR filtered 0.06143、long 0.13514、静默 2/40，
但 anytime 保证变成 0.15，**不再满足 0.10 的预算**。

`AND-look(S, P)` **不可用**：命中掉到 65/125 = 0.520——P 的命中集合几乎是 S 的子集
（only_P = 5、only_S = 38），合取等于被 P 卡住。

- `.05/.10`（早紧晚松，总预算仍是 0.10 的量级）与 `S@0.10` **逐位相同**——早窗里根本没有 α ∈ (0.05, 0.10] 的报警可切；
- `.13/.02`（早松晚紧）把 FAR 压到 0.03754，但命中掉到 **90/125 = 0.720**（−13 条），
  因为 90% 的命中在 look > 64；
- `.03/.12` / `.02/.13`（早紧晚松、总预算超 0.10）命中 105/125，但 FAR filtered 抬到 0.133–0.140、静默 6/40。

**结论：本批上"早窗"几乎是空的（look ≤ 64 只有 6/40 的误报和 13/103 的命中），
`E_view → X` 的动作绝大多数发生在 look 64 之后，两段预算是一个没有杠杆的旋钮。**
（G-conf 描述性读数里"误报聚在 analysis→final 过渡、中位 32.5 looks"是**另一个批、另一个口径**的观察，
本轮**没有也不允许**在 G-conf 上复算；G-dev 上 S 格误报 onset 的中位是 **142 looks**，两者不可直接比。）

## 6. (e) 滞回 / p_inst：连续两个 CONFIRMED look

**先说一个结构性事实**：注册的 `p` 是 **running max 上的保形 p**，在本批上 **2352/2352 个 (episode × 格) 逐条单调不增**。
⇒ **"要求连续 2 个 CONFIRMED look"跑在 `p` 上是恒等操作**（只把 onset 往后挪一个 look，
除非 episode 在下一个 look 就结束）——表里 `S 去抖 2（跑在 running-max p 上）` 与 `S@0.10` **逐位相同**，
FAR、命中、静默、逐折、长度档全部一模一样。**这条必须写进去，否则会被误读成"滞回没用"。**

**真正的去抖只能跑在 `p_inst` 上**（`outputs.jsonl` 的 `p_inst` 列 = 瞬时保形 p，不是 running max）。
规则：`p(k) <= α` **且** 连续 `r` 个 look 满足 `p_inst <= α`，onset 取第 `r` 个：

| 规则 | 命中 | FAR all | FAR filtered | 逐折 | 最差长度档 | 静默 | Δ vs S@0.10（家族聚类） |
|---|---|---:|---:|---|---|---:|---|
| S@0.10 | 103/125 = 0.824 | 0.09804 | 0.11945 | 0.1895/0.0745/0.0962 | long 0.15315 FAIL | 5/40 | — |
| **S 去抖 2** | **102/125 = 0.816** | 0.06618 | **0.07850（−34%）** | 0.1158/0.0426/0.0769 | long **0.10811 PASS** | 2/40 | **−0.008**，CI [−0.029, 0.000]，McNemar p = 1.00（只丢 1 条） |
| S 去抖 3 | 99/125 = 0.792 | 0.03676 | 0.03754（−69%） | 0.0632/0.0213/0.0288 | long 0.07207 PASS | 1/40 | −0.032，CI [−0.070, −0.007]（丢 4 条） |
| M 去抖 2 | 104/125 = 0.832 | 0.08088 | 0.08874 | 0.0842/0.1064/0.0769 | long 0.18018 FAIL | 4/40 | +0.008（M 基线 105） |

**直答：能。** 连续 2 个 look 的 `p_inst` 去抖 **只丢 1 条 X 窗口命中**（103 → 102），
把 filtered FAR 从 0.11945 压到 **0.07850（−34%）**、静默从 5/40 压到 2/40、
最差长度档从 0.15315 压到 **0.10811（F3 从 FAIL 变 PASS）**。
**anytime 保证被继承**（报警集是 `S@0.10` 报警集的子集），**一类性质保持**（`p_inst` 的参照分布同样只来自正常臂）。
代价是 onset 推迟一个 look，且 `F1` 从恒等退化成上界（实测 0.0785 对 0.0946，偏差 0.0161，仍在 ±0.03 内 ⇒ PASS）。
